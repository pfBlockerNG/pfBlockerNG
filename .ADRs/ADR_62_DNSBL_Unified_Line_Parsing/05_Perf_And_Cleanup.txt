WHY THIS PHASE EXISTS
Moving domain extraction off PHP shifts per-update work onto the chrooted single-threaded Python
loader (ADR §3). On a giant hosts feed this could regress wall-clock / memory. ADR §7 reject
criterion 2 makes that falsifiable: this phase measures it against a stated kill-threshold and
removes any code the Phase-4 deletion left dead.
