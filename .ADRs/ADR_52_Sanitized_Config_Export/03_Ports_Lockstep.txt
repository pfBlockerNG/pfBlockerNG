WHY THIS PHASE EXISTS
Release archives contain only `src/`; a new shipped file is invisible to the
package unless it is in the port's pkg-plist AND copied by do-install. PR CI does
NOT build the .pkg, so missing wiring stays green on the package PR but BREAKS the
smoke/release build (build-pkg-portable.py --dry-run hard-fails on plist↔staged
drift). All three ports must be wired, in lockstep with the package change.
