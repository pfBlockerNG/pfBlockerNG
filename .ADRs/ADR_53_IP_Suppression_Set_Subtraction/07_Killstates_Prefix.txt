WHY THIS PHASE EXISTS
The state-kill pass excludes suppressed IPs via an EXACT-IP hashmap: /32
entries verbatim plus a PHP-side /24 materialisation (subnetv4_expand,
pfblockerng.inc:10151-10163). With masks now /8–/32 (P4) and v6 (P6), that map
cannot express the exclusions: a state IP inside a suppressed /16 would still
be killed in the window between saving the suppression and the next table
reload — cutting the exact connections the user just exempted. The Permit
customlist exclusion a few lines down (10296-10301) already shows the correct
prefix-aware shape (ip_in_subnet loop); suppression entries move to the same
pattern.
