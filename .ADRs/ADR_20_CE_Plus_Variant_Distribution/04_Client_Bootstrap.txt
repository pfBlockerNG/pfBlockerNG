WHY THIS PHASE EXISTS
`add-repo.sh` currently writes a static URL of the form
`pfblockerng.github.io/pkg/${ABI}` (the ADR-17 CE-only path). A Plus user running
this script would get a CE-catalog URL, fetch CE packages, and hit a dep error. The
fix is auto-detection of the variant using `globals.plus.inc` (already verified
reliable by the live probe, 2026-06-09) and writing the variant-correct static URL
`pfblockerng.github.io/pkg/${VARIANT}/${ABI}`. This makes `add-repo.sh` the correct
bootstrap mechanism even if the routing layer (Phase 5) is never built or goes down.

   ```sh
       VARIANT="plus"

   ```

   `https://pfblockerng.github.io/pkg/${VARIANT}/${ABI}`

   is unchanged.
