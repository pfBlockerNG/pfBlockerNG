   ```text
   skipped (not blocked); a line with a valid custom scheme is still blocked.

     http://<unique-http>.<tld>      (valid scheme → blocked)

   Given: none of the three domains are in DNSBL.
     Assert BEFORE: drill @127.0.0.1 <http-domain>    → NOERROR (not blocked yet).
     Assert BEFORE: drill @127.0.0.1 <evil-domain>    → NOERROR (not blocked yet).
     Assert BEFORE: drill @127.0.0.1 <skipped-domain> → NOERROR (not blocked yet).

   When: pfb_scheme_strict='on' written to config; feed loaded; pfBlockerNG DNSBL update;
         Unbound reloads.

   Then:
     drill @127.0.0.1 <http-domain>    → sinkhole VIP or NULL (http:// valid, blocked).
     drill @127.0.0.1 <evil-domain>    → sinkhole VIP or NULL (evil:// valid, blocked).
     drill @127.0.0.1 <skipped-domain> → NOERROR (123:// invalid → skipped, NOT blocked).
   ```

   ```text
     (toggle off: 123:// stripped silently, host blocked — current behavior preserved).
   ```
