2. CHANGE `pfb_dnsbl_strip_scheme()` return type to `string|false` with toggle-gated
   RFC 3986 validation. The function must accept a `bool $strict` parameter:

   ```php
   function pfb_dnsbl_strip_scheme(string $line, bool $strict = false): string|false {
       $pos = strpos($line, '://');
       if ($pos === FALSE) {
           return $line;
       }
       if ($strict) {
           $scheme = substr($line, 0, $pos);
           if (!preg_match('/^[a-zA-Z][a-zA-Z0-9+\-.]*$/', $scheme)) {
               return FALSE;
           }
       }
       $remainder = substr($line, $pos + 3);
       if ($strict) {
           // A single trailing '/' is the root path — normalise it away.
           if (str_ends_with($remainder, '/')) {
               $remainder = substr($remainder, 0, -1);
           }
           // Any remaining '/' means an actual path is present — reject.
           if (strpos($remainder, '/') !== FALSE) {
               return FALSE;
           }
       }
       return $remainder;
   }
   ```

   Note: the `$strict` parameter defaults to `false` so Phase 1's oracle tests pass without
   modification (they call the function without the second argument). The path check only fires
   in strict mode — non-strict path stripping continues downstream at lines 9679–9706 as before.
   `str_ends_with()` requires PHP 8.0+; this ADR targets PHP 8.3.
