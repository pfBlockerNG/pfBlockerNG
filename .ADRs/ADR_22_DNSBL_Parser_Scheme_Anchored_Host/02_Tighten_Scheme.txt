ACTION PLAN (ordered)

1. CHANGE `pfb_dnsbl_strip_scheme()` return type to `string|false`:

   Accepted schemes, anchored at the start: `http://`, `https://`, `ftp://`.
   All other `://` → return `false`. No `://` at all → return `$line` unchanged.

   ```php
   function pfb_dnsbl_strip_scheme(string $line): string|false {
       if (str_starts_with($line, 'http://') ||
           str_starts_with($line, 'https://') ||
           str_starts_with($line, 'ftp://')) {
           return substr($line, strpos($line, '://') + 3);
       }
       if (strpos($line, '://') !== FALSE) {
           return FALSE;
       }
       return $line;
   }
   ```

   Notes:
   - `str_starts_with()` is available in PHP 8.0+; this is PHP 8.3 — use it.
   - The three `str_starts_with` checks are the anchored scheme check: `://` must be at
     position 4 (`http`), 5 (`https`), or 3 (`ftp`) from the start.
   - The fallback `strpos($line, '://')` catches any `://` NOT starting with an accepted
     scheme (e.g. `telnet://`, `garbage://`, `evil.com://junk`) → returns `false`.
   - If no `://` is present at all → `return $line` (unchanged; no scheme to strip).
