phase is safe to land independently: the behavior of every feed line is byte-identical.

1. DEFINE `pfb_dnsbl_strip_scheme(string $line): string` in `pfblockerng.inc`:

   Place it near `pfb_strip_trailing_port()`.
   Phase 1 signature: `string` only (no `false` yet — that's Phase 2).
   This is EXACTLY the current inline logic, wrapped in a function:

   ```php
   function pfb_dnsbl_strip_scheme(string $line): string {
       if (strpos($line, '://') !== FALSE) {
           return substr($line, strpos($line, '://') + 3);
       }
       return $line;
   }
   ```
