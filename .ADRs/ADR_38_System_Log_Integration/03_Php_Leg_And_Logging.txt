WHY THIS PHASE EXISTS
The pfSense package <logging> registration is the single mechanism that gives us (a)
a dedicated local file + system.log de-dup, and (b) — critically for Phase 4 — the
`-l /var/unbound/var/run/log` chroot socket (only the static element installs it;
see ADR §1.2.2). Landing it here, with the simpler PHP emitter, proves the local
routing end-to-end before the chroot/python complexity.
