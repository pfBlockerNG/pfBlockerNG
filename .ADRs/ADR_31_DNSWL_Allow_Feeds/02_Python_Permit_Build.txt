WHY THIS PHASE EXISTS
A subscribed DNSWL feed is "a feed every host of which is an implicit @@||host^
allow" (ADR §2). The matcher + precedence already handle band-2 allows; this phase
teaches the BUILD to route a permit feed's hosts into that same band-2 whiteDB store.
mode absent/'deny' must build byte-identically (Phase 1 oracle guards this).

   optional `mode` field: 'permit' vs absent/'deny'. Absent ⇒ 'deny' (back-compat,

2. For a mode=='permit' feed: for EVERY host line of its raw feed, extract the host

   allow (same store/shape as @@||host^ at :4700-4711). Tag provenance so a report can
   attribute the allow to its DNSWL feed (match the existing provenance convention).
3. mode absent/'deny' ⇒ the existing block build path, UNCHANGED.
4. Tests (extend the Phase-1 module or a sibling):
