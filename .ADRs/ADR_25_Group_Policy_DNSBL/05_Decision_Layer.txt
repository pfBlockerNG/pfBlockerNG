ACTION PLAN (ordered — tests alongside)
1. Load policy-groups + alias->bit + CIDR map + allow/deny + default policy from the manifest
   (Phase 4 shape) at build/reload; expose them on the live snapshot like other matcher data.
2. Build gpClientDB: client IP -> (unioned subscribed mask, allow set ref, deny set ref,
   strictest tier) using the Phase-2 CIDR resolver; cache per IP; an unmatched IP -> default
   group. Clear gpClientDB on the ADR-10 atomic swap alongside decisionDB.
3. In operate(): after the group-agnostic base match (domain alias bitmask + allow/deny
   membership), apply SS2.3 precedence per the client's gpClientDB entry:
   allow-hit -> PASS; else deny-hit -> BLOCK; else (domain_mask & client_mask) -> BLOCK or
   WARN (strictest tier); else PASS. WARN = let Unbound resolve normally AND emit the DNSBL
   log/report line (would-be block), reusing the existing logging path with pfb_addr.
4. Apply the Phase-1 cache scheme so a pass/warn client cannot let a block client escape
   (e.g. no_cache_store on policy-relevant names when group policy is on). Keep decisionDB
   storing the GROUP-AGNOSTIC base match (domain-keyed) — only the per-client action layer is
   client-dependent.
5. Preserve OFF-state: group policy disabled -> the new layer is bypassed entirely; legacy
   gpListDB bypass continues to work (now expressible as a migrated Bypass group, but the old
   path must remain correct for un-migrated runtime state / python_control).
6. Tests (every branch; assert before THEN after per CLAUDE.md):
   - OFF-state parity (oracle byte-identical).
   - allow-wins; deny-block; subscribed-alias BLOCK; subscribed-alias WARN (resolves + logs);
     no-match PASS; default group (unmatched IP) = all-aliases Block.
   - union across two groups (subscriptions OR'd; allow>block>warn merge).
   - migrated legacy bypass = PASS for its IPs.
   - CNAME-chain decided against the single snapshot; gpClientDB + decisionDB cleared on swap
     (stale verdict not re-served).
   - the cache-scheme invariant: model the C-cache hazard at unit level (a pass client's
     resolution does not change the block client's verdict).
