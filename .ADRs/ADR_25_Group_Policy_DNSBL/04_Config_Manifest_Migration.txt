ACTION PLAN (ordered)
1. MANIFEST ADDITIONS (all additive-optional; absent => today's behaviour):
   - 'gp_groups': dnsbl Feed-Group name -> bit index. MIRROR Phase 3's assignment — one
     source of truth: emit the map the build derived, never recompute independently.
   - 'gp_divergent_mask': int per SS2.2 (a') — union of bits of (i) groups referenced by any
     binding with an override, (ii) policy_only groups, (iii) groups referenced by any
     SCHEDULED binding.
   - 'gp_clients': per enabled CG {name, cidrs: [literal v4/v6 addresses/CIDRs]} — alias
     refs resolved via the pfSense aliases table at build time; nested aliases resolved
     recursively with a depth guard; FQDN members EXCLUDED with one notice line.
   - 'gp_domain_rules': per CG {allow: [...], deny: [...]} (decoded textareas, validated).
   - 'gp_bindings': per CG, list of {group_bit, override: 'block'|'warn'|'bypass'|'',
     sched_ranges: [...]} — ranges TZ-EXPLICIT (emit the resolved timezone identifier + the
     raw ranges, or pre-resolved absolute windows; pick ONE strategy, justify it against the
     chroot-TZ trap in the handoff — the Phase-1 spike notes may already dictate one).
   - Dangling schedule ref => empty ranges = always in force (fail-open) + notice; dangling
     Feed-Group ref => binding skipped + notice; disabled CG/binding => omitted entirely.
