ACTION PLAN (ordered)
1. Live-VM smoke: inject a config with (a) a stored feed whose catalog url moved (stored url in
   the catalog past_urls) and (b) a stored feed whose catalog status is discontinued.
   - mode=notify: run Recheck -> assert config byte-identical AND both changes are reported.
   - mode=auto: run Recheck -> assert the moved feed's url is rewritten AND the discontinued
     feed is disabled (state), the row still present (not deleted); re-run -> no further change
     (idempotent). Assert the BEFORE state then the AFTER state for each.
   - mode=off: run Recheck -> nothing happens.
   Use inert catalog/fixtures; never RFC 6761 TLDs / HSTS-preload names for any domain data.
2. Maintainer MANUAL checklist (RESULTS + ADR SS7) for anything CI can't cover (a real package
   upgrade carrying such a config).
3. Docs: extend docs/misc/architecture-notes.md with the reconciler (index, plan, modes,
   triggers, never-delete); update README if workflow changed; add stubs for new pfSense fns.
4. Re-confirm DoD + reject criteria: if header-keyed matching mis-fires on real configs or auto
   cannot be made idempotent/non-destructive, record cases and recommend reduce-to-notify or
   reject.
