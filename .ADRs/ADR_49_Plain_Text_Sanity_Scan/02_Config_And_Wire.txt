ACTION PLAN (ordered)

1. Register the field in pfb_cfg_registry() (pfblockerng_extra.inc), grouped with
   the other pfb_feed_* toggles:

       // ADR-49: opt-in plain-text feed sanity scan. Checkbox 'on'|''(off).
       // Default off (absent = off = today's behaviour: the scan never runs).
       'pfb_feed_sanity' => [
           'section'       => $gen,
           'default'       => '',                       // absent -> Off (new-install default too)
           'read_adapter'  => 'pfb_cfg_toggle_read',
           'write_adapter' => 'pfb_cfg_toggle_write',
           'since'         => '4.0.0',
       ],

   Verify against config-gateway.md that PfbToggle's absent/'' -> Off and 'on' ->
   On, and that default '' preserves today's behaviour (feature is new; off = the
   scan never ran ⇒ no grandfather-seed needed, unlike pfb_alias_delta_mode).
   Add the field's config path to the RequireConfigGateway sniff $registeredPaths.

2. Wire the gate in pfb_download(), immediately after the FILE_MIME accept
   (after the `if (!$file_type) {...}` block, ~L9404). Default-off ⇒ put the
   FLAG check FIRST so an off install short-circuits before the MIME check and
   the file read (ADR-28 conv 2: cheapest guard first; the common case is off):

       // ADR-49: opt-in plain-text sanity scan on accepted text feeds.
       if (PfbConfig::read('pfb_feed_sanity') === PfbToggle::On &&
           in_array($file_type, array('text/plain', 'text/html', 'text/csv'), TRUE)) {
           // Read UP TO 8 KiB — a cap, not a minimum; a shorter feed is read whole.
           $pfb_sanity_sample = (string) @file_get_contents($file_download, FALSE, NULL, 0, 8192);
           $pfb_sanity = pfb_text_sanity($pfb_sanity_sample);
           if ($pfb_sanity !== NULL) {
               pfb_validate_log($header, 'plaintext', $pfb_sanity, basename($file_download));
               unlink_if_exists($file_download);
               return FALSE;
           }
       }

   - Confirm $file_download is the right var (the accepted text body); adjust to
     whatever the downstream text parser reads if the code shows otherwise.
   - MIME scope is EXACTLY {text/plain, text/html, text/csv} — application/json,
     application/x-ndjson, inode/x-empty are deliberately NOT scanned (§2.1).
   - The 8192 in the read is the ONLY size literal; it is a cap. Do not add any
     minimum-size check.

3. No GUI. No www/ change. No other call site.
