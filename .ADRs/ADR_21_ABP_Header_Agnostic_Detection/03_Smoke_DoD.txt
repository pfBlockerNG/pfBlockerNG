1. ADD one `smoke` + `timeout(300)` marked test to `tests/smoke/test_smoke_feeds.py`

   `test_abp_perline_detection_in_plain_feed`

   Scenario: `||block^`, `@@||allow^` alongside plain domains in a non-ABP
   custom-list feed → correct block/allow resolution after pfBlockerNG DNSBL update.

   ```text
   Background:
     A Custom_List feed (no ABP header) containing three entries:
       ||<unique-block>.<tld>^
       @@||<unique-allow>.<tld>^
       <unique-plain>.<tld>     (plain block — used to verify @@|| overrides it)
     where <unique-allow> is also added as a plain block in the same list:
       <unique-allow>.<tld>
     (This tests that @@|| overrides even a plain block in the same feed.)

   Given:
     pfBlockerNG DNSBL is enabled; the custom list is not yet loaded.
     Assert: drill @127.0.0.1 <block-domain> → NOERROR (not blocked).
     Assert: drill @127.0.0.1 <allow-domain> → NOERROR (not blocked).
     Assert: drill @127.0.0.1 <plain-domain> → NOERROR (not blocked).

   When:
     The custom list is added; pfBlockerNG DNSBL update is run; Unbound reloads.

   Then:
     drill @127.0.0.1 <block-domain> → sinkhole VIP or NULL (blocked by ||domain^).
     drill @127.0.0.1 <allow-domain> → NOERROR, real/NXDOMAIN response (NOT blocked,
       because @@||allow^ overrides the plain block for that domain).
     drill @127.0.0.1 <plain-domain> → sinkhole VIP or NULL (plain block, unaffected).
   ```

   Implementation notes:
   - Use `helpers.unique_domain()` for each of the three domains; **never** RFC 6761
     TLDs; **never** HSTS-preload names.
   - Inject the custom list via pfBlockerNG's DNSBL Group Custom_List mechanism
     (match how existing smoke tests inject custom entries).
   - After the update, use `wait_unbound_ready` before asserting DNS responses.
   - Clean up in `finally`: remove the custom list entry and re-run the DNSBL update.
   - @pytest.mark.timeout(300) on the test function.
   - Assert BLOCK shape: NOERROR + sinkhole VIP or `0.0.0.0`/`::` (per "Block shapes
     (python mode)" in CLAUDE.md). Do NOT assert NXDOMAIN for a feed-block match.
