WHAT THE MODULE NOW DOES
------------------------
- Module skip removed; joins the ADR-04 smoke fan-out (10 tests).
- pass_order is set explicitly per test via the IP-settings config path (the
  test_smoke_lan_rule_preserve pattern); function-scoped fixtures re-materialize the list
  config per test, so no case leaks its pass_order or reload state into a sibling.
- Trap config wired: Permit_* + Deny_* v4 lists on LAN + a user Block PREPENDED ahead of the
  baked "Default Allow LAN to any rule" (standard admin layout; makes the order_0/order_4
  PERMIT probes decisive) + that baked allow reused as the user pass.
- Data-plane probes (ADR-41 §7): civm-driven TCP SYNs through the LAN pf group, killstates-style
  instrument — pf state formation = pass; no state + rule packet-counter delta = active block.
  Both pfctl -k directions are killed pre-probe (single -k kills by SOURCE only; a stale
  dst-state from an earlier parametrized order otherwise false-reads as reachable).
- All config-order index assertions run within the LAN pf-group projection (non-floating,
  interface == lan), mirroring the off-appliance oracle — the flat filter/rule array
  interleaves the smoke image's baked MGT rules (incl. an empty-descr row), which broke the
  first live run's flat-index predicates.
