HOW REGISTRATION WAS KEPT DRY
------------------------------

The 10 entries are built via a foreach loop over $log_types, appended to the
first half of the $registry array:

  $log_types = [
      'log', 'errlog', 'extraslog', 'ip_blocklog', 'ip_permitlog',
      'ip_matchlog', 'dnslog', 'dnsbl_parse_err', 'dnsreplylog', 'unilog',
  ];
  foreach ($log_types as $log_type) {
      $registry['log_rotate_' . $log_type] = [
          'section'       => $gen,
          'default'       => 'off',
          'read_adapter'  => NULL,
          'write_adapter' => NULL,
          'since'         => '3.2.0',
      ];
  }

The main $registry literal is then merged with the remaining entries via
array union ($registry = $registry + [...]). The loop mirrors how the
log_max_<type> set is logically grouped; the $log_types array is the single
source of truth for both the loop and the test data providers.
