## Design decisions

### `select-box.sh -- "$_bootstrap"` (one-string arg)

`select-box.sh` uses `_SB_CMD="$*"` (P2-frozen), which space-joins all args after `--`. Passing
a PRE-ENCODED single-quoted bootstrap string as ONE arg preserves the shell structure on the box.
Single-quote encoding via `_sq()` (sed `s/'/'\''/'g`) is in local-smoke.sh for REF/ABI/MARKER
values that may contain shell metacharacters.

### run-smoke.sh uses `set --` (not numbered-var trick for passthrough)

The passthrough is SAVED to numbered vars (_pt_N) before `set --` rebuilds the canonical prefix,
then replayed. This avoids bash-isms (no arrays) while preserving arg quoting for -k expressions
like "a and not b".

### DIAG_DIR empty guard: `or "smoke-diag"` not `or Path("smoke-diag")`

Python's `Path("")` is NOT `Path("smoke-diag")` — it resolves to cwd, which escapes the CI
upload globs (`smoke-diag/**`). The `or` treats both `None` and `""` as absent. Pinned by the
`test_empty_env_uses_default` test.

### LAN socket port determinism (TOCTOU fix)

Old: `_alloc_free_tcp_port()` bind(:0) — port released before QEMU opens LISTENER → race window.
New: `DEFAULT_LAN_SOCKET_PORT = _lane_port(12340, _LANE)` — port is KNOWN before boot starts.
The lease + pkill contract on the box frees any prior holder before the smoke boots.

### Ceiling: 5319 not 5745

12340 is now the highest base port (LAN socket). `12340 + 5319*10 = 65530 ≤ 65535`;
`12340 + 5320*10 = 65540 > 65535`. Old ceiling (5745) was based on 8080 (web).

## What is NOT in P4 (deferred or out of scope)

- The full live-VM 2-box concurrent run validation (requires LXC boxes; dispatch after merge).
- Multi-lane SMOKE_LANE >0 concurrent runs (the port-striding mechanism is in place; the
  `select-box.sh` lease already emits `SMOKE_LANE=0` for single-box runs; multi-lane
  dispatching is a separate concern).
- `SMOKE_GHCR_TOKEN` propagation from CI secrets to the box (the `select-box.sh -- <cmd>`
  bootstrap can pass it as an env var if `select-box.sh` emits it; left to the box
  pre-provisioning for now).
