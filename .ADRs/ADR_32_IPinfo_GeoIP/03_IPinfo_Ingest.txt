WHY THIS PHASE EXISTS
IPinfo now ships GeoIP in CIDR IPv4/IPv6 form with a field set that differs from MaxMind's
MMDB. This phase converts that DB into the Phase-2 normalized record, modelling MaxMind-only
capabilities (locale, deprecated flags) as "unavailable".

- FIRST, read .ADRs/ADR_32_IPinfo_GeoIP/RESULTS/02_Results.txt — the normalized record shape.
  If missing, STOP and report.

- src/usr/local/pkg/pfblockerng/pfblockerng.sh — existing GeoIP/ASN download + convert (the
  pattern to extend); the path* var convention for privileged binaries.
- CLAUDE.md — Shell standards (POSIX sh, LC_ALL=C on sorts, path vars), URL-encoding gate,
  Test coverage; PFBL-01 (validate before exec/path build).

ACTION PLAN (ordered)
1. POSIX-sh download of IPinfo's CIDR v4/v6 GeoIP DB (token-authenticated; honour the
   URL-encoding gate). Validate inputs before any exec/path build (PFBL-01).
2. Parse the CIDR DB into the normalized record; map IPinfo fields to the record; set
   capability flags (supports_locale=false; deprecated MaxMind flags absent).
3. Commit small INERT sample fixtures (RFC 5737/3849 IPs, no real tokens) under a tests
   fixtures dir; do NOT ship them in the package.
4. Tests: parse fixtures -> normalized record (exact field mapping); malformed/empty input
   rejected; capability flags correct; LC_ALL=C on any sort over the DB.

CONSTRAINTS
- POSIX sh only; quote expansions; absolute paths only for privileged binaries via path*.
- stdlib/base utilities only in shell; no bash-isms.
- Do NOT wire IPinfo into the consumers yet (Phase 4). Do NOT change MaxMind behaviour.
