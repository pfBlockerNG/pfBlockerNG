   active? }. Read-only (check cache read-only at most; never write).
2. pfb_diag_ip($ips): validate each IP (is_ipaddr) BEFORE pfctl; for each active pfB_* urltable

   alias dir files.
3. Tests (PHPUnit): DNSBL match types (exact / parent-wildcard / TLD / CNAME-in-chain) on
