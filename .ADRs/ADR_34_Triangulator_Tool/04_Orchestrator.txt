ACTION PLAN (ordered)
1. pfb_triangulate($input, $type='auto'): auto-detect IP (is_ipaddr) / domain (PFB_FILTER_
   DOMAIN) / URL (parse_url -> host); for domains/URLs: resolve -> dnsbl(domain+chain) ->
   ip(final ips); for IPs: ip() directly (+ optional reverse). Assemble the report struct.
2. Classify the block mechanism: pure-DNSBL / pure-IP / hybrid / via-CNAME / via-TLD /
   SafeSearch / DoH-DoT-DoQ / IDN / TLD-Allow (derive from the engine results + existing mode
   detection). Attach a plain-English explanation per classification (incl. the
   "whitelisting the IP has no effect on a DNSBL block" guidance).
3. Tests (PHPUnit): each classification branch from a fixtured combination of resolve/dnsbl/ip
   results (exact DNSBL; CNAME-in-chain DNSBL; TLD; pure IP; hybrid; clean/no-match); assert
   the explanation text per branch; assert NO config/cache mutation across a full run.
