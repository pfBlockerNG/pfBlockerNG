WHY THIS PHASE EXISTS
The meta-package's pkg-post-install (Phase 2) and add-repo.sh (Phase 4) must BOTH compute the
box's catalog subtree `<varver>/<arch>` (e.g. `ce-2.8/amd64`, `plus-26.03/aarch64`) on-box, in
POSIX sh, with NO Worker. To avoid two divergent implementations, extract ONE shared helper and
pin it first. The mapping must match the Python `catalog_name_from_version()` exactly, so a box
resolves the same subtree the build pipeline created.
