               (Direct GitHub Pages URL — NO Worker, NO ${ABI} variable; ADR-39 §2.)
Mirror type:   none

## 7. build-pkg-portable.py change (adr/39-meta-package-distribution)

Added: _gh_wrksrc_subdir(mk, workdir) → str
  Computes the tarball subdir from WRKSRC relative to WRKDIR.
  - Standard port (WRKSRC = .../pfBlockerNG-4.0.0.alpha.2/src):  returns "src"
  - Meta-package (WRKSRC = .../pfBlockerNG-4.0.0.alpha.2):       returns ""

Updated: acquire_source()
  Old: hardcoded tops[0] / "src" for ALL USE_GITHUB ports.
  New: uses _gh_wrksrc_subdir(); copies the full tarball root when subdir == "".
  Backward-compatible: existing ports with /src suffix are unaffected.
