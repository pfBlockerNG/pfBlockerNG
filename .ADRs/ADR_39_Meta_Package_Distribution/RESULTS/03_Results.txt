MATRIX-COLLISION GUARD (new)
-----------------------------

File: tests/test_matrix_collision_guard.py

Functions:
  _load_build_matrix() — runs `sh scripts/read-version-matrix.sh --print-build`;
    returns None when script/ref unavailable; callers skip gracefully.
  _collision_pairs(matrix) — returns pairs sharing (freebsd_major, arch) with
    DIFFERENT (php_version, py_flavor). ADR-39 §1.3 invariant: ABI is NOT 1:1 with
    a pfSense version, so two matrix entries may share an ABI — but MUST carry the
    same (php, py) or the catalog keying is ambiguous.

Tests:
  test_real_matrix_has_no_abi_php_py_collision — PASSES on the real matrix (or
    pytest.skip when ci-metadata unavailable). GREEN on current supported-versions.json.
  test_collision_guard_detects_colliding_fixture — proves the guard is live:
    BEFORE: clean_matrix (same php+py) → _collision_pairs() returns [] (no collision)
    AFTER:  colliding_matrix (freebsd_major=15/arch=amd64, php=8.3 vs php=8.5) →
            _collision_pairs() returns exactly 1 pair — guard fires
