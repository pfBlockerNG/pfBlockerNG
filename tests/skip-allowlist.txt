# tests/skip-allowlist.txt -- recorded skip allowlist for scripts/check_skip_allowlist.py
# (issues #2359 and #2369). One entry per line: <suite>:<classname>::<name>, the id the script derives
# from each suite's JUnit report (`#` starts a comment; blank lines ignored).
#
# Every entry MUST carry a trailing `# <reason>` comment -- an entry with none is a parse
# error (exit 2), so this file cannot rot into a bare id list with no record of WHY a test
# currently skips. Add a legitimately new skip as its own entry with its own reason; never
# widen an existing reason to cover an unrelated test.
#
# An allowlisted id this run did NOT observe is informational only (exit 0 unaffected) --
# the skip set legitimately differs per matrix leg (a PHP-build-gated case skips on PHP 8.3
# and not 8.5), per host OS (a macOS-only case skips on CI's Linux runner) and per invoking
# uid, so a local run may observe MORE skips than CI (any chmod/permission-guarded case that
# denies only under a non-root uid). Only an id observed in a report but absent from this
# file fails the gate.
#
# An entry is "<id>  # <reason>" with TWO OR MORE spaces before the '#', and the split takes
# the RIGHTMOST one, so ids keep every '#' they carry -- a pytest parametrised id renders
# its parameter verbatim, even when that parameter contains the separator shape itself, and
# PHPUnit names an unnamed data-set case `testFoo with data set #0`. A single space before
# the '#' is a parse error, not a guess.
#
# Copy an id from the report the suite wrote, never from its source: a pytest parametrised
# id can be index-derived (channel_args1), and the checker replaces XML-illegal control
# bytes with '?' before parsing, so an id built from a description carrying one is recorded
# in that replaced form. PHPUnit writes a bare <skipped/> with no message, so the gate can
# name an unlisted PHPUnit skip but never its reason -- read the suite output for that.
