── Key design decisions ─────────────────────────────────────────────────────────────────────
AMENDMENT A: Rule 4 uses AFTER_PYTEST="${STRIPPED#*-m pytest }" and checks for tests/smoke in
             AFTER_PYTEST; bare `python -m pytest` (no path) produces empty AFTER_PYTEST →
             not flagged. test.yml's unit runner stays green.
AMENDMENT B: --civm-mac defaults to empty; masking/redaction only fires when non-empty.
             scrub --keep takes a pattern and preserves subtrees matching it via -not -path.
AMENDMENT C: _rl_legs() prints filtered JSON to stdout (captured by callers needing LEGS);
             scope=, ci_matrix=, pytest_k= go to GITHUB_OUTPUT via >> file.
AMENDMENT D: all scripts compute self-dir first, then source the lib and call pfb_scrub_git_env.
AMENDMENT E: guard Clause 1 greps --include='*.sh' (primary: bare git token not masked by lib);
             allowlist is secondary (lib, guard, spec).

── Guard self-exclusion fix ─────────────────────────────────────────────────────────────────
Guard Clause 1 now uses --include='*.sh' to exclude Markdown files. scripts/README.md's new
"CI / local-smoke shared scripts" table row describes the guard in prose containing "unset GIT_DIR"
as documentation — that is not a production call and must not be flagged. Limiting the grep to
*.sh files is the correct principled fix (Markdown is never a production call site).
