OBJECTIVE
Add scripts/build-leg.sh — the missing "build ONE leg" wrapper over sparse-clone-ports.sh +
build-pkg-portable.py with a SINGLE unified arg set — plus its shellspec, then rewire the THREE
build sites to call it and DELETE their step divergences. Today each site hand-rolls the same two

any per-leg job body re-grows build step logic (including inline arg-derivation one line above the

This phase was adversarially pre-verified (a Map→Design→Verify pass over the real files). The
seven AMENDMENTS below are findings from that pass — they are mandatory, not optional polish; two

DELIVERABLES

--- scripts/build-leg.sh (NEW) ---
A POSIX-sh wrapper. USAGE:
  build-leg.sh [--ports-repo OWNER/NAME] [--ports-ref REF] [--channel devel|stable|nightly]
               [--abi ABI] [--py-flavor PYxx] [--php X.Y] [--local-src DIR]
               [--pkgversion V] [--annotate K=V]... [--ports-dir DEST] [--out-dir OUT]
Behaviour: prepare the ports tree at REF, build ONE .pkg into the run-keyed OUT dir, print the
resolved absolute .pkg path (and NOTHING else) on stdout. Mirrors build-pkg-portable.py's
path-on-stdout contract so callers do `PKG="$(build-leg.sh ...)"`.

Params + defaults (every param defaults; sites differ ONLY in values + whether
--pkgversion/--annotate are supplied):
  --ports-repo  default 'pfBlockerNG/FreeBSD-ports'  -> wrapped to https://github.com/<repo> (URL,
                sparse-clone arg1). Also accept a file:// URL (the parity gate needs it).
  --ports-ref   default 'pfblockerng/use-github'     -> sparse-clone arg2. (Makes release.yml's and
                smoke-single.yml's hard-coded ref a parameter.)
  --channel     default 'devel'   -> sparse-clone arg4 AND builder --channel (one source, kills the
                YAML's duplicate channel passing).
  --abi         default 'FreeBSD:15:amd64'  -> builder --abi (TARGET fact, never read from the tree).
  --py-flavor   default 'py311'   -> sparse-clone arg6 AND builder --py-flavor.
  --php         default '8.3'      -> sparse-clone arg5 AND builder --php.
  --local-src   default '.'        -> builder --local-src.
  --pkgversion  default '' => OMIT the flag (builder derives PORTVERSION from the ports Makefile/
                channel). A non-empty value => forward --pkgversion V. THIS single param is the
                build-pkg-linux(omit)/release($portversion)/smoke(literal) divergence.
  --annotate    repeatable; default none => no --annotate flags. Each value => one builder
                --annotate K=V.
  --ports-dir   explicit sparse-clone DEST; default = ${PFB_PORTS_DIR:-$PFB_RUN_DIR/ports}.
  --out-dir     explicit builder --out; default = ${PFB_OUT_DIR:-$PFB_RUN_DIR/out}.

Keying (source scripts/lib/run-id.sh — the SAME chokepoint select-box.sh uses; do NOT duplicate id
logic): RUN_ID = $RUN_ID if already exported, else mint via the lib (CI: GITHUB_RUN_ID set ->
pfb_mint_run_id_ci; local -> pfb_mint_run_id_local "${PFB_BOX:-$(hostname)}").
PFB_RUN_DIR := ${PFB_RUN_DIR:-${PFB_RUN_ROOT:-/var/tmp/pfb-runs}/$RUN_ID}. OUT and DEST default as
above (run-keyed => two concurrent runs never collide on the builder's deterministic {pkgname}.pkg
filename — ADR §5.1). `mkdir -p` DEST and OUT idempotently. Resolve SCRIPT_DIR via
`cd "$(dirname "$0")" && pwd` so the helpers are found regardless of caller CWD (exactly like
sparse-clone-ports.sh). Scrub GIT_* at the top (reuse the shared scrub helper if P5 has landed it;
else `unset` inline as sparse-clone does).

Call sequence:
  Step 1 (tree):  sh "$SCRIPT_DIR/sparse-clone-ports.sh" "https://github.com/$PORTS_REPO" "$PORTS_REF" \
                     "$DEST" "$CHANNEL" "$PHP" "$PYFLAVOR" 1>&2      <-- AMENDMENT 1: redirect Step 1
                  stdout to STDERR so git-checkout chatter never pollutes build-leg's stdout.
  Step 2 (build): PKG="$(python3 "$SCRIPT_DIR/build-pkg-portable.py" --ports "$DEST" --channel \
                     "$CHANNEL" --local-src "$LOCAL_SRC" --abi "$ABI" --py-flavor "$PYFLAVOR" --php \
                     "$PHP" [--pkgversion "$PKGVERSION" iff non-empty] [--annotate "K=V" per item] \
                     --out "$OUT")"
                  printf '%s\n' "$PKG"    <-- the ONLY thing on build-leg stdout.
Optional flags are appended to the argv ONLY when set, so an unset --pkgversion/--annotate is
byte-identical to today's omission. `set -eu`; quote every expansion; absolute paths only for
privileged binaries per CLAUDE.md shell rules (python3/git/sh are base — bare is fine).

--- parity-guard lint (NEW: tests/shell/<name>_spec.sh scanning .github/workflows/*.yml) ---
FAIL CI if any per-leg job body carries BUILD step logic. AMENDMENT 4 + 5 (the guard must
discriminate by TARGET and deny-by-default, or it both false-positives the blessed call and misses
hidden derivations):
  FLAG (fail):
    - any direct invocation of build-pkg-portable.py OR sparse-clone-ports.sh in a workflow (every
      build MUST go through build-leg.sh);
    - --pkgversion / --annotate / a ports github.com URL / a ports ref literal ONLY when they are
      arguments to build-pkg-portable.py or sparse-clone-ports.sh (a direct builder/clone call) —
      NOT when on a build-leg.sh call;
    - a build-leg.sh argument VALUE that is NOT a literal, a workflow ${{ inputs.* }}, a
      ${{ matrix.* }}, or a ${{ needs.*.outputs.* }} expression — i.e. a command-substitution or a
      locally-derived env feeding the build leg is denied by default (this is the teeth: inline
      derivation one line above the call is caught because the VALUE is non-conforming, not because
      we enumerated the bad command).
  ALLOW (orchestration, not flagged): the single build-leg.sh invocation with conforming arg
    values; the matrix DEFINITION + the fan-out jq that selects per-entry coords; select-box.sh
    --print-id / RUN_ID mint / LEG assignment; checkout/setup-python/ensure-zstd/upload-artifact;
    the post-build rename for artifact naming.
  Pin the guard with fixtures (a passing workflow snippet + each failing class), exemplar-style.
  Scope = the build sites for P3; P5 generalizes to test/smoke legs.
