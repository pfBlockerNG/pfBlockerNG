WHY THIS PHASE EXISTS
ADR-45 adds a structural-probe layer to pfb_download(): after the file(1) MIME
gate, ask the native archive tool "is this actually a parseable archive of this
type?" before extraction. Before wiring anything into a call site (Phases 2/3),
this phase lands the two pure/seamed helpers the later phases call, with oracle
tests that pin their contract:

  1. pfb_archive_probe(string $canonical_type): ?array
     A PURE function: canonical archive MIME -> the base argv (binary + flags) of
     its native integrity test, or NULL for a non-archive type. No I/O, no file
     argument — the file is appended by pfb_validate_archive() at call time. This
     keeps probe trivially oracle-testable (string in -> array/NULL out).

  2. pfb_validate_archive(string $file, string $canonical_type, ?callable $runner = NULL): bool
     Runs the probe via an INJECTABLE runner so the decision logic is unit-tested
     off-appliance with NO shell. Returns TRUE for a non-archive type (nothing to
     test), TRUE on a passing probe (exit 0), FALSE on a failing probe.

This phase is behaviour-preserving: NEITHER helper is called from pfb_download()
or pfb_filter() yet. No functional change to any existing path. (Same shape as
ADR-44 Phase 1, which added pfb_mime_in_allowlist() + oracle tests with no
call-site change.)

1. Add pfb_archive_probe() near the other pure MIME helpers (just after
   pfb_mime_normalise(), ~L666). Map per ADR §2:

       application/zip               -> array('/usr/bin/tar', '-tf')
       application/gzip              -> array('/usr/bin/gunzip', '-t')
       application/x-gzip            -> array('/usr/bin/gunzip', '-t')   (alias)
       application/x-bzip2           -> array('/usr/bin/bzip2', '-t')
       application/x-7z-compressed   -> array('/usr/local/bin/7z', 't')
       anything else                 -> NULL

   NOTE on the binary: ADR §2 writes "bsdtar -tf"; on FreeBSD base /usr/bin/tar
   IS bsdtar and is the path pfb_download() already uses for ZIP listing
   (L8350/L8376) — use /usr/bin/tar for consistency. Return the binary+flags
   only; the file is NOT part of probe's output.

2. Add pfb_validate_archive() immediately after it:

       function pfb_validate_archive(string $file, string $canonical_type, ?callable $runner = NULL): bool {
           $argv = pfb_archive_probe($canonical_type);
           if ($argv === NULL) {
               return TRUE;            // non-archive: nothing to test
           }
           $argv[] = $file;            // file appended here, escaped in the runner
           if ($runner === NULL) {
               $runner = function (array $a): int {
                   $cmd = implode(' ', array_map('escapeshellarg', $a));
                   exec($cmd . ' >/dev/null 2>&1', $out, $rv);
                   return (int) $rv;
               };
           }
           return $runner($argv) === 0;
       }

   The default runner escapeshellarg()s every argv element (binary, flags, file),
   discards stdout/stderr, and returns the exit code. Injecting `$runner` lets the
   decision logic be tested with no shell.
