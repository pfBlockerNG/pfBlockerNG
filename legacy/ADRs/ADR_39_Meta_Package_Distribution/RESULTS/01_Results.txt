HELPER FILE + INTERFACE
--------------------------------------------------------------------------------

File: scripts/lib/detect_variant.sh
Type: sourceable POSIX sh (no shebang; intended to be `. scripts/lib/detect_variant.sh`)

Functions exposed (all print to stdout via printf, no trailing newline):

  pfb_detect_edition
      Prints "Plus" if globals.plus.inc is present, else "CE".
      Detection: [ -f "${PFB_GLOBALS_PLUS_INC}" ]

  pfb_detect_version
      Prints the trimmed version string from /etc/version.
      E.g. "2.8.1" (CE) or "26.03.1" (Plus).

  pfb_detect_arch
      Prints the bare arch leaf parsed from `pkg config abi`.
      E.g. "FreeBSD:15:amd64" → "amd64";  "FreeBSD:16:aarch64" → "aarch64".
      Parsing: IFS=: read -r os major arch from the abi string; prints arch.

  pfb_detect_varver
      Prints "<edition_lower>-<major>.<minor>" — the catalog variant token.
      E.g. "ce-2.8", "plus-26.03".
      Mapping: lowercase(edition) + "-" + cut -d. -f1,2(version).
      Mirrors catalog_name_from_version() in scripts/build-repo-portable.py exactly.

  pfb_detect_catalog
      Prints "<varver>/<arch>" — the catalog subtree for this box.
      E.g. "ce-2.8/amd64" or "plus-26.03/aarch64".
      This is the path segment appended to the channel prefix in the repo conf URL.

STDOUT CONTRACT:
  Every function prints its result with printf (no trailing newline beyond the value
  itself).  Callers that capture via $(...) receive the value with no extra whitespace.

--------------------------------------------------------------------------------
globals.plus.inc — RESOLVED PATH + EDITION LOGIC
--------------------------------------------------------------------------------

Real path on box: /etc/inc/globals.plus.inc
Detection variable: PFB_GLOBALS_PLUS_INC (default: /etc/inc/globals.plus.inc)

Source resolution: confirmed live by ADR-20 Phase 1 (2026-06-09):
  - CE 2.8.1:     /etc/inc/globals.plus.inc ABSENT  → edition = CE
  - Plus 26.03.1: /etc/inc/globals.plus.inc EXISTS  → edition = Plus
  - Method: `[ -f /etc/inc/globals.plus.inc ]`

Path sourced from pfSense open-source repo `src/etc/inc/globals.plus.inc`
(as referenced in ADR-20 §1 and the Phase-1 live probe results).

The helper uses the path via PFB_GLOBALS_PLUS_INC so tests can inject a fixture
path without touching the real filesystem.

--------------------------------------------------------------------------------
ARCH PARSING FROM `pkg config abi`
--------------------------------------------------------------------------------

`pkg config abi` output format: "FreeBSD:<major>:<arch>"
  Examples:
    FreeBSD:15:amd64    → arch leaf = amd64
    FreeBSD:16:aarch64  → arch leaf = aarch64

Parsing technique: IFS=: read -r _pfb_os _pfb_major _pfb_arch (POSIX, no awk/cut).
The OS and major fields are consumed by `read` and discarded (silenced via `: "${var}"`).
The arch leaf is the third colon-delimited field.

PFB_PKG_CMD overrides the pkg binary path for tests (default: pkg).
