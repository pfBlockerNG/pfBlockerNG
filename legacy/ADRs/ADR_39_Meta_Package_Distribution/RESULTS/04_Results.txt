  test_generate_hook_rewrites_stale_varver_and_resolves
                                                      REGENERATE PATH, before+after:
        BEFORE: seeded conf url carries stale "stale-9.9/<arch>"; assert the real
                <varver>/<arch> is NOT present.
        WHEN:   fire the hook (PFB_BASE_URL=file://<base>).
        AFTER:  url flips to the box's REAL <varver>/<arch> (stale gone) + canonical
                marker; `pkg update` accepts; our package installs with its files.
        ORACLE: the hook's folded detection is cross-checked against an independent
                Python oracle (_box_real_catalog) — disagreement => catalog unreachable
                => pkg install fails loud.
        IDEMPOTENCE: a second hook run leaves the conf byte-identical (pure regenerate).
