ROLE
You are on the `adr/16` branch performing Phase 5 of ADR-16. Add a live-VM smoke that loads

WHY THIS PHASE EXISTS
The HTTP feed-fetch path (curl → matcher) is built but NEVER tested — every existing case feeds
a LOCAL file, and the harness comment hints local files were chosen partly for HTTP-fetch
reliability (Context 5). This phase composes the proven pieces (mock server + curl + load/assert
helpers + System-DNS→mock wiring) for an actual feed fetch — the gap Part C closes — and treats
the reliability as a kill-gate (ADR-01/ADR-10 discipline: falsify the premise cheaply first).
