WHY THIS PHASE EXISTS
The user wants Feeds organized like IP/DNSBL/Reports. But the save loops ALL types and writes
`$_POST['feed_x'] ?: ''` (Context 2) — so a per-type tab that POSTs only its own fields would
RESET every other type's rename to ''. The split is therefore impossible WITHOUT type-scoping
the save. This phase does both together, guarded by the Phase-2 oracle + a new non-clobber test.
