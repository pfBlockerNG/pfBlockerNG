ACTION PLAN (oracle-driven — each parse class tested vs the Phase-2 spec)
1. Define the Rule dataclass (replaces ParsedEntry for the abp path; keep ParsedEntry for the
   'plain'/'hosts'/'csv:pon' paths unchanged):
     Rule(kind: block|allow, target: domain|regex, key_or_pattern: str,
          important: bool, badfilter: bool, provenance: user|feed,
          feed: str, group: str, log: str, signature: tuple)
   signature = (normalised-pattern, tuple(sorted DNS-options)) MINUS $badfilter — the
   $badfilter match key (Phase 5 uses it).
2. Implement the FULL DNS-only parser: parse('abp', line, *, provenance, feed, group, log)
   -> Rule | None (extend the dispatcher; the abp branch becomes the full parser, the others
   stay as ADR-06 left them):
   - BLOCK domain: ||domain^ (+options), hosts `IP domain` (take the domain), plain domain.
   - ALLOW domain: @@||domain^ (+options).
   - REGEX: /re/ (block), @@/re/ (allow) — store the raw pattern as target=regex; reduction
     is Phase 5, compile/load is Phase 6, runtime safety is Phase 7 (DO NOT compile/execute here).
   - $OPTIONS: parse the `$...` suffix; KEEP the rule only if every option is DNS-relevant
     ($important/$badfilter and any agreed DNS modifiers) AND the target is a bare domain or
     a regex; otherwise return None. SKIP page-context ($third-party/$domain=/$script/
     $image/$csp/...). Set important/badfilter flags from the options.
   - SKIP ALWAYS (return None): element-hiding ##/#@#/#?#/#%#/#$#, path/URL rules
     (anchored to a path), comment/control lines (!/[), and IP-VALUED anchors (||1.2.3.4^,
     hosts IP) — those are the firewall path (Phase 8); _dnsbl_is_ipv4 gate.
   - Domain targets still go through normalise() (lower-case + shape gate) before becoming a
     Rule key; an invalid domain -> None.
3. Unit-test EVERY class exhaustively (tests/test_adr07_parser.py) against the Phase-2 spec:
   every KEEP and every SKIP line type, $options keep/skip, important/badfilter flag-setting,
   provenance plumbing, IP-anchor skip, and the reducible-vs-irreducible regex tag (just the
   classification flag; reduction itself is Phase 5).
4. Keep it import-safe and Unbound-symbol-free (pure).
