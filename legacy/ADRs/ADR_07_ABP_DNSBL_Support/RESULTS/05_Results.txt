1. THE reconcile() API  (what Phase 6 consumes)
================================================================================
  reconcile(rules: Iterable[Rule],
            tlds: dict[str, dict[str, str]],
            exclusion: set[str]) -> ReconcileResult

PURE + REENTRANT: builds + returns a FRESH ReconcileResult; mutates no argument
and no module global; never compiles/executes a regex. Two calls on equal inputs
yield equal results (test_reconcile_twice_equal; test_reconcile_does_not_mutate_
inputs; test_no_global_mutation).

INPUTS:
  * rules     -- the Stage-A Rule stream (parse_abp output, P4). Each caller (the
                 Phase-6 build()) supplies feed/group/log/provenance on the Rule;
                 reconcile does NOT re-derive them. USER-provenance rules
                 (settings block list, user regex, whitelist, TOP1M) MUST be
                 parsed with provenance=RULE_PROV_USER so they reach bands 5/6 and
                 are $badfilter-immune (fact 7).
  * tlds      -- the public-suffix oracle, EXACTLY the shape build() already holds:
                 _dnsbl_load_tld_master(...) -> tlds[tld][full-suffix]. Pass the
                 SAME `tlds` build() computes (build():2329).
  * exclusion -- the TLD-exclusion set, EXACTLY build()'s
                 `exclusion = {e.strip(".") for e in tld_exclusion}` (build():2327).
  tlds/exclusion are the classify() inputs; reconcile reuses the ADR-06 classify()
  unchanged (no reimplementation).

================================================================================
@dataclass ReconcileResult (all lists default-empty; counts default 0):

  block_domains: list[BlockDomainRule]
  allow_domains: list[AllowDomainRule]

  key: str            registrable parent (ZONE) | exact domain (DATA), from classify
  band: int           PRIO_* band (1/3/5)
  important: bool     carried $important (set the dataDB/zoneDB payload `important`)
  provenance: str     RULE_PROV_FEED | RULE_PROV_USER
  feed: str           } manifest-row metadata -> feed_group_index_db + the payload
  group: str          }
  log: str            } -> the payload "log" flag

@dataclass(frozen=True) AllowDomainRule -> whiteDB ({wildcard, important}):
  domain: str
  wildcard: bool      True -> domain + subdomains; False -> exact
  band: int           PRIO_* band (2/4/6)
  important: bool     -> the whiteDB[d]["important"] field
  provenance: str

@dataclass(frozen=True) RegexRule -> regexDB (block) / allowRegexDB (allow):
  pattern: str        the RAW inner regex pattern -- NOT compiled (Phase 6 compiles)
  kind: str           DNSBL_KIND_BLOCK | DNSBL_KIND_ALLOW
  band: int           PRIO_* band
  important: bool     -> the {"re","important"} payload (P3 widened both DBs accept
                        this shape; or carry band directly for the numeric branch)
  provenance: str
  feed/group/log: str manifest-row metadata for the "DNSBL_Regex" group + counts

3. HOW $badfilter / REDUCTION / CLASSIFY / BANDING ARE ENCODED
================================================================================
$BADFILTER PRUNE (Step 1, feed-only):
  bad_sigs = {r.signature for r in rules if r.badfilter and r.provenance==FEED}
  Then: drop every rule with r.badfilter (it emits nothing -> skipped_badfilter++);
  drop every FEED rule whose r.signature in bad_sigs (-> pruned++). USER rules are
  NEVER in bad_sigs and NEVER pruned (immune, fact 7). Matches oracle reconcile().
  Signature recap (P4 SS1): (key_or_pattern, sorted DNS-opts) MINUS $badfilter, so
  ||x^$badfilter (sig ("x",())) prunes ||x^ but NOT ||x^$important (sig
  ("x",("important",))) -- different option = different sig.

REGEX REDUCTION (Step 2):
  _dnsbl_reduce_regex(inner) -> (wildcard, domain) | None, mirroring the oracle
  reduce_regex + spike reduce_pattern EXACTLY (cross-checked in
  test_reduction_matches_oracle_and_spike). Grammar:
    ^(.+\.)?D$ | (^|\.)D$ | ^(?:.+\.)?D$  -> (True,  D)  wildcard ZONE
    ^D$ | ^(www\.)?D$ (www stripped)      -> (False, D)  exact DATA
  where D = [a-z0-9-] labels joined by ESCAPED dots (\.). Anything else -> None
  (IRREDUCIBLE -> stays a RegexRule with the raw pattern). A reduced regex BLOCK
  folds to a BlockDomainRule (classify decides data/zone); a reduced regex ALLOW
  folds to an AllowDomainRule (wildcard from the fold). reduced++ on each fold.

CLASSIFY (Step 3): for a domain BLOCK, reuse classify(domain, tlds, exclusion):
    wildcard rule (||domain^ / hosts / plain / reduced-wildcard-regex) ->
      classify() -> (ZONE, registrable-parent) or (DATA, deeper-sub).
    exact rule (a reduced /^D$/ with wildcard=False) is FORCED to
      (DATA, domain) -- never wildcarded into a zone (test_exact_fold_forces_data).
  ALLOW domains do NOT classify (they go to whiteDB as {wildcard, important}).

BANDING (Step 4): _dnsbl_rule_band(rule) wraps the P3 helpers:
    _allow_priority(rule.important, user=(prov==USER))  for ALLOW
    _block_priority(rule.important, user=(prov==USER))  for BLOCK
  -> 1 feed block / 2 feed allow / 3 feed block+imp / 4 feed allow+imp /
     5 user block / 6 user allow. Equals oracle priority() for every band
  (test_band_matches_oracle_priority). This wires the user-block -> band 5 the
  P3 handoff (SS3) flagged as un-wired: provenance now drives it via _dnsbl_rule_band.

5. THE important_rules FAST-PATH FLAG  (build() must emit it)
================================================================================
ReconcileResult.important_rules is the build-emitted gate the P3 matcher reads as
cfg["important_rules"] (P3 SS2). reconcile sets it True iff ANY surviving rule
engages the numeric 6-band branch:
    * any rule with $important (feed block/allow + $important), OR
    * any FEED ALLOW (@@) -- a feed exception the fast path's "allow beats block"
      seam handles only via whiteDB; with bands it needs numeric resolution, OR
    * any FEED irreducible regex (block or allow).
It is FALSE for a pure plain/hosts/||domain^ FEED-block set (today's corpus) AND
for a USER-only rule set (the fast path already handles user whitelist + user
blocks; P3 SS3) -- pinned by TestImportantRulesFlag (5 cases). So:
  PHASE 6: emit pfb["important_rules"] = ReconcileResult.important_rules, and
  pfb["allowRegexDB"] = bool(allow_regex_irreducible OR any allow_domains). When
  important_rules is False the matcher stays byte-for-byte today (ADR-06 oracle).
