1. BENCHMARK — branch peak-RAM (build-while-old-live + swap) vs the kill-threshold
--------------------------------------------------------------------------------
  Harness: benchmarks/spike_adr10_swap.py (UNCHANGED), .venv/bin/python (CPython
  3.14, darwin), default SPIKE_SIZES=2000000 / SPIKE_N=3, pympler 1.1 present
  (genuine both-resident sizing, not the 2x-tracemalloc fallback).

  RESULT (all 3 runs identical):
    raw corpus: 2,040,000 lines -> 1,493,123 unique domains (data=1,311,583
                zone=181,540, 24 feedgroups)
    new-set build peak (tracemalloc, one set):    388.4 MiB
    steady-state footprint (one set, pympler):     392.9 MiB  (276.0 B/entry vs
                                                   274 B/entry ADR-05 baseline)
    BOTH-RESIDENT (old + new live, pympler):       785.9 MiB   <== the ~2x number
    process peak RSS (ru_maxrss, whole interp):  2,623.1 MiB

  KILL-THRESHOLD (unchanged from Phase 1): 35% of a 1 GB min-spec box = 358 MiB.
    gate input 785.9 MiB [both-resident, pympler] -> OVER-BUDGET
    RAM VERDICT: RAM-GATED (mitigation required).

  This re-confirms Phase 1 to the byte (785.9 MiB then and now): the ~2x transient
  busts the 1 GB-box budget at ABP scale, so the swap is NOT default-on for a
  constrained box. The MANDATED mitigation is BUILT and is the fail-safe:
    - PHP RAM gate (PRIMARY) — pfb_unbound_py_swap_fits_ram() (Phase 5):
        projected = 2 * loaded_entries * 276 (RELOAD_BYTES_PER_ENTRY);
        fits iff hw.usermem >= projected + 64 MiB (RELOAD_RAM_HEADROOM_BYTES);
        unknown pfb_py_count / unreadable hw.usermem -> FALSE (fail-closed -> restart).
    - Python watcher free-page probe (SECONDARY net) — declines fail-closed on a
        constrained box, keeping the old snapshot (Phase 4).
    Either declining -> fall back to today's RESTART, which never doubles RAM (the
    old set dies before the rebuild). The 276 B/entry + 64 MiB headroom are one
    contract shared by both ends.

  Bonus-2 micro-bench (Reports-sqlite write, informational, unchanged from P1):
    (a) per-row INSERT+commit  9.21 us/row (worst case, not shipped);
    (b) batched executemany    0.69 us/row (what pfb_db_worker does off-thread);
    (c) queue.put_nowait       1.122 us/row (the only DNS-thread-path cost) ~1.12x
        the ~1 us matcher. Async log path retained + reset-on-swap (Phase 3), per
        the Phase-1/3 decision.
