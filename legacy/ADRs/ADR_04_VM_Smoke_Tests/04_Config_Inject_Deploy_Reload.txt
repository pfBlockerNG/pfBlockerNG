ACTION PLAN (ordered — pin each helper with a self-test)
1. DEPLOY HELPER: wrap `scripts/deploy.sh <ssh-target>` to push the current working
   tree's `src/` onto the VM, then confirm the reload entry runs (php
   pfblockerng.php update exit 0). Self-test: after deploy, a file we changed is

2. CONFIG-INJECTION HELPER (`php -r` over SSH): given a case spec (feed url(s) +
   alias name, DNSBL response mode, whitelist entries, wildcard/exact, AND the case's
   control-domain local-data: {name -> A/AAAA} + any local-zone), apply it to the VM's
   pfBlockerNG config AND Unbound config via the pfSense config API (parse_config /
   config_get_path / config_set_path / write_config). The control records are Unbound
   Host Overrides / Custom Options (local-zone:/local-data:) so passthrough/whitelist
   cases resolve hermetically under blocked egress — set them HERE in config (NOT via
   live `unbound-control`) and BEFORE the feed `update`, so they survive the reload that
   regenerates unbound.conf. Keep it declarative: input a small dict/dataclass, emit the
   php that sets exactly those fields. Self-test: inject a value, read it back via php,
   assert it stuck; inject a control name, query it, assert it resolves.
3. RELOAD/RESET HELPERS: `reload(scope)` -> php pfblockerng.php
   update|updatednsbl|updateip (prefer the targeted verb for speed); `reset()` ->
   clearip/cleardnsbl (+ reload) to return to a known baseline per the isolation
   strategy from 03_Results.txt.
4. DNS PROBE HELPER: query the VM (dnspython or `dig` via ssh/local) for (name, type);
   return (rcode, records). Provide assert helpers: is_nxdomain, is_null_ip(addr),
   is_vip(addr), resolves_to(addr). FALSE-GREEN GUARD (ADR §2 contract): a test that
   asserts the WRONG shape MUST fail — include such a negative self-test.
5. IP PROBE HELPER: `pfctl_table_members(alias)` (ssh `/sbin/pfctl -t <alias> -T show`)
   and `rule_references(alias)` (ssh `pfctl -sr` | grep). Asserts: a fed IP is a
   member; a non-fed IP is not; a rule references the alias.
6. Wire 1-5 as a single per-case context/helper (set -> reload -> probe -> reset) the
   matrix will call. Mark any test that touches the VM `@pytest.mark.smoke`.
