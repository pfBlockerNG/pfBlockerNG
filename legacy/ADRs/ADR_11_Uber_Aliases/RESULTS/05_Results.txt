7. ADR-12 HAND-OFF (explicit)
--------------------------------------------------------------------------------
What ADR-12 / HAProxy consumes from ADR-11:
  * The Native urltable aliases pfB_<Type>_Aggregated_{v4,v6} (referenceable by is_alias();
    a `source_ip` ACL makes the HAProxy package emit ipalias_<alias>.lst).
  * The never-empty `-f` consumer .lst files (a `#` placeholder line when empty) -> a
    downstream `-f` reference always validates / reloads (no /../../ or dummy-IP hack).
Freshness model (NOT a socket push):
  * pfBlockerNG LOADS each aggregate's pf table INLINE (pfctl -T replace -f) BEFORE the ADR-12
    `post` update hook fires -> a hook always sees the FRESH table.
  * A rebuilt aggregate's name is merged into PFB_CHANGED_IP_ALIASES (mtime-gated: an
    unchanged type adds nothing).
  * HAProxy re-reads its `-f` ACL files only AT RELOAD (the runtime socket cannot inject ACL
    data) -> freshness = a pfBlockerNG-triggered GRACEFUL HAProxy reload from a `post` hook
    (the README HAProxy recipe), NOT a socket push.
