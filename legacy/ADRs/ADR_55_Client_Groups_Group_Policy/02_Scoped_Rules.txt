ACTION PLAN (ordered)
1. GENERATOR: after the existing per-group rule emission, iterate enabled CGs x enabled
   ipv4/ipv6 bindings: action = action_override ?: FG default_action; skip if resolved
   action is Alias_*/Disabled and no override (policy-only FG with default-inherit binding
   emits NOTHING — assert); build via pfb_firewall_rule() with:
   - outbound shapes: asrc_out = pfB_CG_{cg} (invert flags NOT exposed on bindings),
   - inbound shapes: adest_in = pfB_CG_{cg},
   - log = log_override ?: group logging; gateway/ports/proto inherit the FG's Advanced
     fields exactly as the default rules do (one code path, not a fork);
   - rule descr: pfB_{fg}_CG_{cg}{$pfb['suffix']} (deterministic tracker; pfB_ prefix keeps
     pfb_is_managed_obj() ownership; assert <= the descr length the tracker/UI tolerate);
   - sched = binding sched when the named schedule exists, else omit + notice.
   Binding rules append INTO the same accumulators (deny_inbound etc.) BEFORE that FG's
   default rule is appended, so within-bucket order = edges before defaults (SS2.3).
2. VALIDATOR (save-time, shared by Phase 3 UI): the dead-override matrix — resolved
   Deny_* override on a Permit_*-default FG => input_errors with the EXACT SS2.3 message.
   Permit-override-on-Deny-default is allowed (the carve-out case). Encode as a pure
   function returning [ok|error, message]; table-driven.
3. RULE-COUNT helper: pure function (config -> per-CG and total generated-rule counts,
   accounting for Both = 2 shapes, families, float vs interface stamping) for the Phase 3
   pages.
4. CHANGE GATE: prove binding add/edit/remove flows through the existing
   $orig_rules_nocreated != $new_rules_nocreated comparison -> filter_configure() flag;
   no new filter_configure() call sites.
5. TESTS (red->green each): the SS7 matrix — {Deny,Permit,Match} x {In,Out,Both} x {v4,v6}
   x {override, inherit} x {sched,none}; policy-only FG + binding (only scoped rules
   exist); disabled CG/binding emits nothing (before+after); dangling FG ref skipped with
   notice; dangling sched emits unscheduled; ADR-41 oracle extended: binding rules land in
   the correct buckets for order_0..4 and user rules stay immutable; first-match conflict
   fixture: client in 2 CGs, Permit-override + Deny-default -> pass rule precedes (assert
   final array order).
6. Gates: full phpunit + linters; pytest untouched (prove no python/manifest diff).
