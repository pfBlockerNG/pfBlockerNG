WHY THIS PHASE EXISTS (read carefully — the original spike is moot)
ADR-09 was authored when "can a GH runner build our port into an installable .pkg
cheaply?" was unproven, so Phase 1 was a kill-gate spike. That risk is GONE:
  * `build-pkg-linux.yml` -> `scripts/build-pkg-portable.py` is the DEFAULT builder:
    it executes the port's own recipe + pkg-plist on a PLAIN LINUX runner (pfBlockerNG
    is a NO_BUILD port), and was diffed byte-for-byte against a real `make package`
    artifact (exact except mtime + a few binary-repo dep versions).
  * `build-pkg.yml` runs the REAL `make package` on an ABI-matched FreeBSD VM and is
    retained as the FIDELITY ORACLE / FALLBACK ("Linux by default, FreeBSD if we fuck
    up").
So there is nothing to spike. Inventory both, document their inputs (notably the
(freebsd_version, php_version) pair), and hand Phase 3 a precise contract.
