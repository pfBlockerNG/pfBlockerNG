WHY THIS PHASE EXISTS
The TOP1M provider URL is chosen by a hardcoded if/else on the Top1mSource enum
(pfblockerng.php:162). Adding providers by extending that if/else does not scale
and spreads per-provider facts across files. Introduce ONE descriptor table now,
with tranco+cisco only, so later phases add a provider as a table row. No new
provider and no behaviour change in this phase — this de-risks all that follows.
