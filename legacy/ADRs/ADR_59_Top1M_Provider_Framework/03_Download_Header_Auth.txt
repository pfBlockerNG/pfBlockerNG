caller sets a header yet). Inline, one commit, push directly.

WHY THIS PHASE EXISTS
pfb_download() offers only Basic-auth + query-param URLs; the ADR-42
conditional-GET owns CURLOPT_HTTPHEADER and REPLACES the whole list. Cloudflare
Radar (Phase 5) needs `Authorization: Bearer <token>`. Wire caller-supplied
headers now, merging with the conditional-GET header — so Phase 5 is a descriptor
row, not surgery on the downloader.

ACTION PLAN
1. Add an `$extra_headers = array()` parameter to pfb_download() and thread a new
   per-feed field `$feed['headers']` through pfblockerng_download_extras().
2. In the cURL branch, when `$extra_headers` is non-empty, MERGE it with the
   conditional-GET header into a single CURLOPT_HTTPHEADER list — do NOT clobber
   If-None-Match, and vice-versa. Keep the header values OUT of any log.
3. No provider sets `headers` yet. Basic-auth (MaxMind) + query-param (asn)
   paths unchanged.
