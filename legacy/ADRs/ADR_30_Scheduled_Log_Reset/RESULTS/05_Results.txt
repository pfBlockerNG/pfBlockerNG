SMOKE SCENARIOS (§2.2 contract)
---------------------------------

Case 1 — boundary reset + inode preserved + per-log independence
  (test_boundary_reset_inode_preserved_and_per_log_independence)

  Given:
    - ip_blocklog schedule = daily; marker = yesterday (stale).
    - ip_permitlog schedule = off; no marker entry.
    - Both logs seeded with inert RFC 5737 content.
    - ip_blocklog inode captured via ``ls -i``.
  Before-state asserted: ip_blocklog non-empty; ip_permitlog non-empty;
    marker ip_blocklog = stale key; no ip_permitlog marker entry.
  When: ``h.reload(vm, "update")`` (pfblockerng.php update → pfb_log_reset).
  Then:
    - ip_blocklog EMPTY.
    - ip_blocklog inode UNCHANGED (in-place ``/bin/cp /dev/null`` truncation).
    - ip_permitlog UNTOUCHED (schedule=off; per-log independence proved).
    - marker ip_blocklog = today's daily key.
    - marker ip_permitlog absent.

Case 2 — same-period idempotency
  (test_same_period_is_idempotent)

  Given:
    - ip_blocklog schedule = daily; marker = today's key (current period).
    - Log seeded with inert content after the marker write.
  Before-state asserted: ip_blocklog non-empty; marker = today's key.
  When: ``h.reload(vm, "update")``.
  Then:
    - ip_blocklog NOT emptied (content identical to before).
    - marker ip_blocklog still = today's key.

Case 3 — chrooted python log (dnslog) reset + inode + unbound ownership
  (test_chrooted_python_log_reset_preserves_inode_and_ownership)

  Given:
    - dnslog schedule = daily; marker = yesterday (stale).
    - dnslog seeded with inert content at the effective host path
      (/var/unbound/var/log/pfblockerng/dnsbl.log when chroot dir exists,
       else /var/log/pfblockerng/dnsbl.log — mirrors pfb_log_reset logic).
    - File chowned to unbound:unbound (production state).
    - inode captured; owner asserted = 'unbound'.
  When: ``h.reload(vm, "update")``.
  Then:
    - dnslog EMPTY.
    - dnslog inode UNCHANGED.
    - dnslog owner still 'unbound' (pfb_log_reset re-chowns after truncation).
    - marker dnslog = today's daily key.

Case 4 — all schedules off (no reset, stale markers preserved)
  (test_all_off_no_log_emptied)

  Given:
    - ALL 10 log_rotate_<type> = 'off'.
    - ip_blocklog and ip_permitlog seeded with inert content.
    - Marker entries for both set to yesterday (would trigger reset if enabled).
  Before-state asserted: both logs non-empty; stale markers present.
  When: ``h.reload(vm, "update")``.
  Then:
    - ip_blocklog UNTOUCHED (content identical to before).
    - ip_permitlog UNTOUCHED.
    - Marker file UNCHANGED (pfb_log_reset only writes when $changed is TRUE).
