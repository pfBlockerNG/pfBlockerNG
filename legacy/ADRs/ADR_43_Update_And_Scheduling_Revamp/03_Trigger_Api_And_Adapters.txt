WHY THIS PHASE EXISTS
The $cron string overloads trigger+scope+force. Phase 1 pinned the exact mapping; now make the named
request the real API so callers stop guessing, while keeping every old verb working (deprecate-then-
remove, per the ADR's chosen back-compat). "force vs reuse" is defined against ADR-42's content
detector (the prerequisite): force=false ⇒ respect the detector (unchanged ⇒ no reparse, the
#517-style no-change pass); force=true ⇒ always reparse.
