### pfblockerng_safesearch.php

Section: `installedpackages/pfblockerngsafesearch` (flat, all keys registered).

LOAD:
- `config_get_path('installedpackages/pfblockerngsafesearch', [])` →
  `PfbConfig::readSection('installedpackages/pfblockerngsafesearch')`

SAVE:
- `config_set_path('installedpackages/pfblockerngsafesearch', $pfb['bconfig'])` →
  `PfbConfig::writeSection('installedpackages/pfblockerngsafesearch', $pfb['bconfig'])`

Page-local defaults (`?: 'Disable'`) for `safesearch_enable`, `safesearch_youtube`,
`safesearch_doh` and `safesearch_doh_list` match registry defaults but were left in-place:
the section-blob approach does not call `PfbConfig::read()` per field, so the defaults are
applied only when the key is absent from the loaded array. Removing them would change
behaviour if the config key is present but empty — kept to preserve exact prior logic.
