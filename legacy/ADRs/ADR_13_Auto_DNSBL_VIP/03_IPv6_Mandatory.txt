ROLE
You are on the `adr/13` branch performing Phase 3 of ADR-13. This phase enforces the
correctness rule: when the DNS Resolver listens on IPv6, a v6 sinkhole VIP becomes
mandatory — auto mode provisions it, manual mode requires it. Work inline on `adr/13`,
one commit, push directly (PR only if rejected).

WHY THIS PHASE EXISTS
A blocked AAAA needs a real v6 sinkhole when the resolver answers over/returns IPv6;
silently lacking one is a latent gap. The detection helper (pfb_unbound_listens_v6) already
exists (Phase 1). This phase consumes it in validation + provisioning. NOTE the reject/pivot
lever in §7: if forcing v6 on existing manual, v6-listening setups proves too disruptive,
soften manual mode to a non-blocking WARNING (auto mode still provisions). Decide here.
