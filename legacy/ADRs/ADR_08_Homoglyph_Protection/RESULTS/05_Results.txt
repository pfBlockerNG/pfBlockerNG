4. THE DUAL-FORM LOG LINE (xn-- + decoded + offending script)
-------------------------------------------------------------
  _idn_dual_form(verdict) picks the WORST label (first label whose severity == the name
  verdict's — name severity is the most-severe label) and formats:
      "<a_label> [<decoded>] <offending scripts, space-joined, sorted>"
  Examples (verified):
      xn--pple-43d.com           -> "xn--pple-43d [аpple] Cyrillic Latin"
      xn--ypal-43d9g.example.com -> "xn--ypal-43d9g [раypal] Cyrillic Latin"  (subdomain
                                     homograph — per-label, never unioned across the dot)
      a FLAGGED decode error     -> "<a_label> [decode-error:UnicodeDecodeError]"
  This string is the b_eval on a BLOCK (overrides the bare A-label after the generic
  `b_eval=q_name`, only on the homoglyph path) AND the b_eval inside idn_alert on an ALERT.
  It mirrors the alerts page's existing idn_to_utf8 "domain [decoded]" display so the
  dnsbl.log/unified.log line + the alerts page render it actionably.
  Block line: get_details_dnsbl's existing CSV (p_type,b_type,group,b_eval,feed) — b_eval
  carries the dual form. Alert line: _log_idn_alert emits the SAME columns with b_type
  "Homoglyph_Alert" so a non-block alert is distinguishable.


5. SEVERITY -> ACTION (reproduces the Phase-2 oracle action(); section 3 of RESULTS/02)
---------------------------------------------------------------------------------------
  LEGIT      -> NONE   (single-script, Latin+CJK, IDN-ccTLD per-label) — resolves untouched.
  MALICIOUS  -> BLOCK  when block_malicious (default-ON); -> ALERT when disabled
               (still attributed to the Homoglyph/malicious feed, just not blocked).
  SUSPICIOUS -> ALERT  by default; -> BLOCK when escalate_suspicious (opt-in).
  FLAGGED    -> ALERT  by default; -> BLOCK on escalate. NEVER block-by-default; the
               undecodable case is caught inside classify_idn so it NEVER crashes the
               resolver (asserted: an evaluate_domain over an undecodable xn-- returns
               normally with an alert).
