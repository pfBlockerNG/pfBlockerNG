2. THE ANALYZER'S PUBLIC API  (Phase 5 import surface)
------------------------------------------------------
Module: pfb_idn_analyzer  (importable as a plain module; sibling to pfb_unbound.py,
already on sys.path at runtime and in tests via conftest).

  decode_idn_label(label: str) -> str
      Strip xn--, RAW 'punycode' decode (label[4:].encode('ascii').decode('punycode')).
      Non-xn-- label returned unchanged. NOT the 'idna' codec. MAY raise
      (UnicodeDecodeError / UnicodeError / ValueError) — callers catch it.

  script_of(codepoint: int) -> tuple[str, ...]
      Resolved script(s) of ONE code point: Script_Extensions when present (bisect
      over SCRIPTX_*), else the plain Script (bisect over SCRIPT_*). A transparent
      (Common/Inherited) or unassigned code point -> () (absent from the tables).

  resolved_script_set(text: str) -> set[str]
      Union of script_of over one DECODED label's chars. Common/Inherited transparent
      (contribute nothing). An all-scriptless label -> the EMPTY set (the FLAGGED
      trigger). NEVER unions across the dot (operates on one label).

  restriction_level(scripts: set[str], *, ascii_only: bool = False) -> str
      UTS#39 level: LEVEL_ASCII / LEVEL_SINGLE / LEVEL_HIGHLY_RESTRICTIVE /
      LEVEL_NON_RESTRICTIVE.

  severity_of(text: str) -> str
      ONE decoded label -> SEV_LEGIT / SEV_SUSPICIOUS / SEV_MALICIOUS / SEV_FLAGGED.
      Rule: >=2 of CONFUSABLE_SET co-occur -> MALICIOUS; empty letter-set -> FLAGGED;
      single-script or Latin+CJK (Highly Restrictive) -> LEGIT; else SUSPICIOUS.

  classify_label(a_label: str) -> LabelVerdict
      Decode-safe (NEVER raises). frozen dataclass:
        a_label, decoded (None on decode error), scripts (frozenset),
        severity, offending (frozenset), decode_error (exc type name or None).

  ** classify_idn(q_name: str) -> NameVerdict **   <-- the Phase-5 entry point
      Splits on '.', classify_label PER LABEL, name severity = MOST SEVERE label
      (_SEV_ORDER legit<flagged<suspicious<malicious). NEVER unions across the dot.
      frozen dataclass NameVerdict:
        a_name, labels (tuple[LabelVerdict, ...]), severity, offending (frozenset).
      `offending` = the worst label's offending scripts (for dual-form logging:
      decoded Unicode + offending script/char), per ADR-08 section 2.

  Constants exported (mirror the Phase-2 oracle):
    SEV_LEGIT / SEV_SUSPICIOUS / SEV_MALICIOUS / SEV_FLAGGED,
    LEVEL_ASCII / LEVEL_SINGLE / LEVEL_HIGHLY_RESTRICTIVE / LEVEL_NON_RESTRICTIVE,
    CONFUSABLE_SET = {Latin, Cyrillic, Greek}, CJK_COMPANIONS = {Hiragana, Katakana,
    Hangul, Bopomofo}.

  OFFENDING-CHAR RETURN: severity + offending scripts on both verdict dataclasses.
    MALICIOUS -> the >=2 confusable scripts that co-occur (e.g. {Latin, Cyrillic}).
    SUSPICIOUS -> the full multi-script set (e.g. {Latin, Armenian}).
    LEGIT / FLAGGED -> empty frozenset.
  NOTE the API uses severity strings (SEV_MALICIOUS/SEV_SUSPICIOUS/SEV_LEGIT/
  SEV_FLAGGED), NOT a separate "OK" token; SEV_LEGIT == the prompt's "OK". The
  Phase-5 action mapping (malicious->block, suspicious/flagged->alert, legit->none)
  is the oracle's `action(sev, *, block_malicious=True, escalate_suspicious=False)`
  in test_adr08_decision_spec.py — reproduce it at the matcher seam (the analyzer
  deliberately returns severity, leaving the action/toggle policy to Phase 5).
