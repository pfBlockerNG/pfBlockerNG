WHY THIS PHASE EXISTS
The convention must be written down as policy of record (like ADR-28) and applied on the shell side
where pfBlockerNG does file change detection — so the codebase has ONE self-describing, per-side
hashing primitive. Python is recorded as md5 (policy); its code lands with its consumer in the
follow-up DNSBL-reuse ADR (no speculative unused helper here).
