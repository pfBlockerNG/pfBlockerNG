ROLE
Phase 4 of ADR-38 on the implementation branch. This phase FLIPS THE DNSBL LEG ON
(still default-off). It is the RISKIEST phase — chrooted, stdlib-only, hot-path.
One commit, pushed on the branch.

WHY THIS PHASE EXISTS
DNSBL block events are written by the chrooted Unbound python module, which (a) cannot
use UDP (syslogd -s, secure mode), and (b) sees /var/run/log as the in-chroot
/var/unbound/var/run/log socket that Phase 3 registered via <logging><logsocket>.
This phase wires the python emitter to that socket, gated by config, and MUST degrade
silently — a syslog failure can never raise into Unbound or block resolution
(ADR §2.2.4).

ACTION PLAN
1. PHP: at ini-build time, write three keys into py_unbound.ini (e.g.
   `syslog_enable`, `syslog_facility` as the numeric facility, `syslog_priority` as
   the numeric level) derived from the registered settings via PfbConfig + the P2 map.
   Preserve a safe default when absent (disabled).
2. Python: read those keys at the module's config-load boundary (mirror the existing
   ini reads; type-hint). When enabled, lazily create ONE module-level
   `logging.handlers.SysLogHandler(address='/var/run/log',
   facility=<n>)` wrapped so its level maps to the configured priority; guard the
   constructor + every emit in try/except Exception → silently disable (set a flag so
   we do not retry-storm). Emit syslog_format_dnsbl(...) once at the DNSBL CSV write
   site, alongside (not replacing) the existing file write.
3. Ensure ident/tag is `pfblockerng` (so the Phase-3 !pfblockerng routing catches it).
   If SysLogHandler needs an explicit ident in the message, prepend it consistently.
4. Confirm there is no per-query overhead when disabled (the common case): the gate is
   a cheap boolean checked before formatting/emitting.

CONSTRAINTS
- Python 4-space, 3.11+, `from __future__ import annotations`, STDLIB ONLY, no bare
  except (except Exception minimum). The emitter MUST NOT raise into Unbound and MUST
  NOT block the resolve path. Persistent socket — do not reconnect per event.
- Do NOT change the DNSBL decision logic, the CSV format, or the manifest. Add a new
  injected-symbol stub only if you reference one not already in stubs/python/.

EXPECTED RESULT
With the toggle ON, DNSBL block events emit one pfblockerng key=value syslog record
each via the chroot socket; with it OFF (or the socket unavailable), the DNSBL path
behaves exactly as before. Both legs (IP + DNSBL) now honour the single master toggle.
