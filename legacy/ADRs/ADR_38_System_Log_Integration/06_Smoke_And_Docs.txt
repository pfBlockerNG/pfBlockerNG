WHY THIS PHASE EXISTS
Off-box suites prove the formatters, config, and emit gating; only a real pfSense VM
proves the full path: PHP openlog + chrooted python SysLogHandler → the registered
facility → the dedicated log (and, via "Everything", a remote server). The smoke is
what lets ADR-38 reach Accepted without a manual gate (CLAUDE.md ADR-acceptance rule)
for the CI-coverable parts.
