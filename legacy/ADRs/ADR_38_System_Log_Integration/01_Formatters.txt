WHY THIS PHASE EXISTS
The syslog message body must be a stable, SIEM-parseable key=value string derived
from the SAME source fields the existing CSV lines are built from, so the CSV and
the syslog view can never drift (ADR §2.2.3). Extracting + pinning the mapping as
pure functions FIRST de-risks the later wiring: emission becomes a one-line call to
a tested formatter, and a regression in the field mapping fails a unit test, not a
SIEM.
