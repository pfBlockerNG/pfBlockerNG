WHY THIS PHASE EXISTS
The whole ADR rests on two upstream-source facts (read + cited in §1 Context 3):
`pkg_install()` runs `pkg install -y <name>` with NO `-r` (so it resolves across ALL
enabled repos, highest version wins), while only `get_pkg_info()` discovery is
`-r pfSense`-locked. That is reasoning, not a box result. This phase turns it into a
GREEN/RED fact: a third-party repo conf is honored for install, and cross-repo
precedence can be made to favor our build.
