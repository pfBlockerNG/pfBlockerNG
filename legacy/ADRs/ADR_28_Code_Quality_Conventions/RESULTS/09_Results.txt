1. STRING-OPS OVER REGEX (item 4) — SWAPS MADE
------------------------------------------------

Five sites changed in pfblockerng.sh; no changes to list_scripts/ (see §3).

a) Dispatch block (lines 1299-1302, was 1300-1303):
   BEFORE: 4 × `if [ "$(echo "${1}" | grep -c '_255')" -gt 0 ]; then ...`
   AFTER:  4 × `case "${1}" in *_255*) ... ;; esac`
   Rationale: each grep-c is a FIXED SUBSTRING check on a scalar $1 value;
   case glob-pattern is exactly equivalent and avoids four subshells + four
   grep invocations on every `_*` dispatch.

b) whoisconvert() host_check (line 640-691):
   BEFORE: host_check="$(echo "${host}" | grep '\.')"
           if [ -n "${host_check}" ]; then ... else ... fi
   AFTER:  case "${host}" in
           *.*) domain arm ;;
           *)   ASN arm    ;;
           esac
   Rationale: grep '\.' (BRE escaped dot) matches any string containing a
   literal '.'. POSIX case pattern '*.*' is exactly equivalent — same
   semantics, same anchoring (none), same empty/no-dot edge case (no match).
   Eliminates a subshell, an echo, and a grep invocation per host iteration.

c) reputation_max() header extraction (line 848):
   BEFORE: header="$(echo "${alias##*/}" | cut -d '.' -f1)"
   AFTER:  header="${alias##*/}"; header="${header%%.*}"
   Rationale: the echo|cut pipeline extracts the first dot-separated field of
   the basename. ${%%.*} strips from the first '.' to end — exactly equivalent,
   including the edge case where no '.' is present (both return the full
   basename unchanged). Eliminates a subshell + echo + cut.

d) reputation_dmax() blfile header extraction (line 977):
   BEFORE: header="$(echo "${blfile##*/}" | cut -d '.' -f1)"
   AFTER:  header="${blfile##*/}"; header="${header%%.*}"
   Same equivalence argument as (c). This is inside the inner while loop that
   iterates blocklist files per repeat-offender IP — eliminates per-iteration
   subshell overhead.

e) reputation_pmax() blfile header extraction (line 1065):
   BEFORE: header="$(echo "${blfile##*/}" | cut -d '.' -f1)"
   AFTER:  header="${blfile##*/}"; header="${header%%.*}"
   Same as (d).

4. CONSTRUCTS LEFT AND WHY
---------------------------

a) `ls "${etdir}" | sed 's/\.txt//'` (processet, ~line 1145):
   Strips the .txt suffix from a list of ET category filenames to build a
   space-separated list for a downstream `for` loop. A parameter-expansion
   replacement would require a glob-loop that builds a variable across
   iterations — more code, different whitespace/ordering behaviour for the `for`
   consumer. Not equivalent in shape; left as-is.

b) `grep -cv '^#\|^$'` (multiple sites):
   Multi-alternation BRE pattern — comments OR blank lines. No single param-
   expansion or case idiom can replicate counting non-matching lines from a
   file; left as-is.

c) `grep -v ':' ... | grep -v '\.'` (whoisconvert IPv4/v6 filter):
   File-content filters (grep over lines of a file), not scalar string
   comparisons. param-expansion cannot filter file lines; left as-is.

d) `grep -aoEw "(...IP octet...)" | LC_ALL=C sort -u` (processxlsx):
   Genuine ERE IP address extraction from XML content. No param-expansion
   equivalent; left as-is.

e) `sed 's/^.* //'`, `sed 's/$/0\/24/'`, `sed 's/^/\!/'` etc. (multiple sites):
   Substitutions on file content (piped/redirected), not on a single scalar
   variable. param-expansion operates on variables only; left as-is.

f) `grep -c '_255'` etc. in the ASN asn variable build and elsewhere that are
   genuine content searches over files — left as-is.

g) `ip_placeholder2` sed-escape and `ip_placeholder3` cut (~lines 98-99):
   sed 's/\./\\\./g' on ip_placeholder to build a regex-safe version — this is
   PRODUCING a regex escape, not doing a match; a case equivalent doesn't exist
   for producing regex-escaped strings. Left as-is.
