4. CONFIG.XML BYTE-IDENTITY CONFIRMATION
------------------------------------------

Every adopted site is a READ/COMPARE boundary only.  The substitution changes only
the PHP expression that evaluates the stored value to a bool; it never changes:
    - how the value is written to config.xml
    - what value config_set_path() receives
    - any serialization sink

Substitution pattern:
    EXPR == 'on'                                 →  pfb_cfg_toggle_read(EXPR) === PfbToggle::On
    EXPR === 'on' ? TRUE:FALSE,                  →  pfb_cfg_toggle_read(EXPR) === PfbToggle::On,
    EXPR != 'on'                                 →  pfb_cfg_toggle_read(EXPR) !== PfbToggle::On
    isset(K) && EXPR === 'on' ? TRUE:FALSE       →  isset(K) && pfb_cfg_toggle_read(EXPR) === PfbToggle::On,

Byte-identity for PfbToggle over all stored vocab:
    Input 'on'  → old true,  adapter === PfbToggle::On → true   ✓
    Input ''    → old false, adapter === PfbToggle::On → false  ✓
    Input null  → old false, adapter === PfbToggle::On → false  ✓
    Input 'off' → old false, adapter === PfbToggle::On → false  ✓ (junk → Off)
    Input 'yes' → old false, adapter === PfbToggle::On → false  ✓

No stored value in config.xml was modified.  No $_POST path was altered.


5. EQUIVALENCE TESTS ADDED
----------------------------

Two new methods added to tests/php/CfgAdaptersTest.php:

    testP5ReadBoundaryPatternMatchesOldCompare()
        Pins that pfb_cfg_toggle_read($v) === PfbToggle::On produces the same bool
        as ($v == 'on') for all stored vocab ('on', '', 'off', null).
        Asserts before-state (old expression) AND after-state (adapter) for each input.
        Covers negation pattern (!== PfbToggle::On ≡ != 'on') too.

    testP5FormCheckboxPatternMatchesOldTernary()
        Pins that the Form_Checkbox bool-arg pattern ($v === 'on') ? true : false
        is byte-identical to pfb_cfg_toggle_read($v) === PfbToggle::On
        across all four stored-vocab values ('on', '', 'off', null).

Both methods are falsifiable: they fail if the adapter's mapping diverges from
the old comparison for any stored vocab value.
