WHY THIS PHASE EXISTS
The whole retroactive sweep rides on one guarantee: config.xml stored values never change across
upgrade (ADR §1.3 — there is NO migration routine in this package). Enums/booleans are an internal
runtime representation; a field-aware adapter converts stored string <-> internal type with proven
round-trip identity. Landing the tested adapter first means every later enum-adoption phase reuses a
verified seam instead of reinventing it.
