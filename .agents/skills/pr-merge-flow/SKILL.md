# Review and land a PR

Read `../../../.claude/skills/pr-merge-flow/SKILL.md` for the exact external-review and
wait policy. Replace its `review-single` Claude workflow with `$review-single`'s
trusted Codex review controller; never select a reviewer role from the PR
worktree. Use low for the standard and every delta review, high for a
large/complex whole-PR review, and the sequential low-plus-medium fallback when
the documented high tier is unavailable; never fan out unless the user requests
it. Run `$pr-comments` before `$pr-merge`, preserve every required review record,
and apply the canonical `CLAUDE.md` policy through the `AGENTS.md` Codex mapping.
Every public body, reply, and audit comment must replace the canonical Claude
footer/reviewer label with
`🤖 Generated by OpenAI Codex and posted on behalf of @<login>.` Never post Claude
attribution for Codex work.
