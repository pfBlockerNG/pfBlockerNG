Read `../../../.claude/skills/pr-comments/SKILL.md` for the full process. Use
`$triage-findings` for evidence-backed verdicts, `$review-single` for independent
checks, and the available GitHub CLI or configured GitHub MCP tools.

per-thread replies, scope checks, tests, and the final cancellation sweep.

high for a large/complex whole-PR review, and low plus medium only for its
documented high-tier fallback. These remain sequential single-reviewer passes,
not fan-out.

and reviewer label with the truthful Codex footer

Codex output as Claude output; the Claude runtime keeps its own canonical footer.
