# Smoke tests (ADR-04 — live pfSense VM)

Scope: `tests/smoke/` + live-VM harness. Load when: touching `tests/smoke/**` or running smoke/UI suites — READ BEFORE TOUCHING `tests/smoke/`.

`tests/smoke/` installs branch `.pkg` on REAL pfSense CE VM in CI, asserts pfBlockerNG end-to-end. **Run locally first** (no workflow spent): [`docs/misc/local-smoke-debian.md`](../../docs/misc/local-smoke-debian.md), wrapped by `scripts/local-smoke.sh` — already exists; reach for it before asking.

**NEVER remove `.pfb_cron_disable`: every smoke appliance creates it before package install; assert cron registration and invoke `tick` explicitly.**

**Live-VM smoke ALWAYS runs on a real box — never claim "needs CI" or "cannot run on this host".** Two transports; the box you are on picks one. **`ssh smoke` resolves in this box's ssh config** → that host runs every tier: `ssh smoke pfb-test <tier> [--ref <sha>] [--filter <expr>]`, and stdout's LAST line is the results path — cite it in findings. It fetches `--ref` from ORIGIN on the host, so only pushed commits are visible. **It does not** → set `PFB_BOXES` from this box's own configuration and use `scripts/local-smoke.sh`, which leases a box from that pool (ADR-47) and runs whole leg — images, build, pytest — **on that box** over ssh, against box's own toolchain (issue #2513). **No pool address is tracked here**: boxes belong to whoever runs them, one maintainer's pool times out everywhere else, and `tests/shell/select_box_spec.sh`'s addresses are fake boxes for lease-token assertions, never a pool to copy. Dev machine needs only `ssh` (macOS included); box needs every tool `scripts/smoke-on-box.sh` preflights — `git jq curl uv oras python3 ssh qemu-system-x86_64 qemu-img dig iptables zstd tar unzip` — and it fails loud naming what missing, never falls back. Red→green proof for `tests/smoke/**` is EXECUTED on a real box (`--marker`/`--filter` to scope), never dispatched to CI, never reasoned through.

Non-obvious truths, each costly to relearn:

- **Probe ON-BOX** (`drill @127.0.0.1` over SSH), never runner-side SLIRP hostfwd. Python-mode DNSBL has no localhost exemption. After `reload()` then `wait_unbound_ready`, **first** DNS response is authoritative — assert it, never loop for expected value.
- **Test domains MUST be `helpers.unique_domain()`** (`uuid-*.com`): never RFC 6761 TLDs (Unbound built-in `local-zone`s shadow them before DNSBL), never HSTS-preload names (`pfb_hsts` default ON forces would-be VIP block to NULL). Sole carve-out: byte-identity harnesses use fixed inert literals (same two prohibitions apply).
- **Block shapes (python mode):** NOERROR + VIP (`dnsbl_ipv4`) or NULL (`0.0.0.0`/`::`); NEVER NXDOMAIN for feed match (SafeSearch-only). Per-list `logging` selects VIP vs NULL, is LIST-level field, not per-row. Compare IPs by value (`::` == `::0`).
- **Unbound chrooted at `/var/unbound`** — module-read files must be chroot-relative; host-absolute path silently fails to load.
- **pfSense root login shell is `tcsh` — always drive guest via `/bin/sh`.** tcsh silently mangles POSIX syntax (`2>&1`, here-docs, `grep -E` with `()`/`|`/`$`) — once produced false `rules.debug:0` read. `SmokeVM.ssh` already wraps commands in `/bin/sh -c`; do same for anything new or by hand. (`pfSsh.php` snippets are separate stdin/`exec`/`exit` contract.)
- **Enable chain:** DNSBL `mode=='enabled'` needs `enable_cb=on` + `pfb_dnsbl=on` + DNS Resolver enabled (`unbound_state`). On `devel`, `dnsbl_mode`/`pfb_py_block` are dead keys; on `main` still required.
- **Image bakes only deps + qemu-guest-agent** — harness injects DNSBL VIP (`ensure_dnsbl_vip`) + all per-case config; `pkg add` runs offline (RUN_DEPENDS baked via `scripts/misc/install_deps_CE_2.8.sh`); `pfb_dnsvip_auto` defaults OFF, so `ensure_dnsbl_vip` stays fixture. Smoke qcow2 cache content-keyed by GHCR digest.
- **Branch `.pkg` built on plain Linux runner** (`build-pkg-linux.yml` → `scripts/build-pkg-portable.py`) — pfBlockerNG is `NO_BUILD` port; **sole** builder for CI + releases.
- **Every run uploads full guest snapshot** (`smoke-diagnostics`: `/var/log`, `dmesg`, `pfctl -sa`, unbound + pfBlockerNG state, scrubbed `config.xml`). On any failure, read it first.

Web-UI tiers (ADR-14, `tests/smoke/ui/`) + mock-feed load smoke (ADR-16 Part C) documented in architecture-notes. Operative facts:

- **Tier A `ui_render` is PR gate**: GET each page → 200, body free of PHP errors/warnings, page-specific marker present, AND no new on-box `php_error.log` diagnostic **in gated class from pfBlockerNG file** (#1218: guest runs true `E_ALL` — above every level pfSense itself ships, since even dev builds mask `E_WARNING`/`E_NOTICE`/`E_DEPRECATED`. Core noise never gates: `gating_log_lines` scopes by originating file, never by re-masking class. Gated classes are defect-smelling ones — `Undefined variable`, null-to-string-parameter (PHP 9 TypeError in waiting), array-offset-on-null, optional-parameter order — plus fatal/parse/recoverable/strict levels. Endemic `Undefined array key` class (469 sites measured) is REPORTED at end of full sweep, not gated; #1712 burns it down. Pre-existing gated-class sites grandfathered in `tests/smoke/ui/php_diagnostic_baseline.txt`, 33-entry list that may only SHRINK — fix site, delete entry, never append) — never HTTP 200 alone. Surface recorded in `test_render_smoke.py`'s `EXCLUDED_FROM_TIER_A` uses that exclusion's named live tier plus focused hermetic coverage instead. Tiers B otherwise schedule/dispatch-only. Run: `python3 -m pytest tests/smoke/ui -m ui_render --override-ini="addopts="` (`SMOKE_ADMIN_PASSWORD` must be set — UI fixtures FAIL without it; skip is not pass).
- **Selective dispatch:** bare `gh workflow run smoke.yml`/`ui-tests.yml` defaults to `scope=impacted` (min-CE leg + test modules changed vs `origin/devel`); pass `-f pytest_filter="a or b"` to add tests covering changed non-test code; `-f scope=full` = every leg, whole marker. Nightly/`workflow_call` gates stay full. Locally pass `-k`/`-m` to `scripts/local-smoke.sh`. Full reference: architecture-notes "Selective dispatch".
- Fixtures live in `tests/smoke/fixtures/` (inert data — RFC 5737/3849 IPs, `uuid-*.com`; never RFC 6761 TLDs or HSTS-preload names). Add one: file + `fixtures/README.md` + `test_smoke_feeds.py` case via `mock_feeds.feed_url("<name>")`.
