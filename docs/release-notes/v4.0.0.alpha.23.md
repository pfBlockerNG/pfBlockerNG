### Bug Fixes

- Upgrading or reinstalling the package no longer fails during post-install configuration: the package's own resync path could reach the IP-suppression pass with an uninitialized state flag, crashing `sync_package_pfblockerng()` with a `TypeError` and leaving the install half-configured ([#1840](https://github.com/pfBlockerNG/pfBlockerNG/issues/1840)). The flag is now seeded unconditionally for every sync pass. Anyone whose 4.0.0.alpha.22 upgrade errored in POST-INSTALL should reinstall/upgrade to this build.

**Full changelog:** [`v4.0.0.alpha.22` → `v4.0.0.alpha.23`](https://github.com/pfBlockerNG/pfBlockerNG/compare/v4.0.0.alpha.22...v4.0.0.alpha.23)
