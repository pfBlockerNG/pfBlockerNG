<!-- SUMMARY: cleaner update log -->
This is an alpha of the 4.0.0 series and is intended for testing. Do not run it on a
production firewall without a configuration backup; feedback and bug reports are welcome.

## Improvements

- **ISO-8601 dates in the update log and List Summary**, matching the rest of the logs.
- **Tidier update log** — removed the blank line between each alias "Updating:" entry.

## Bug Fixes

- **No more spurious `pfctl: Table does not exist` lines** in the update output: reading an
  alias whose pf table does not exist yet (e.g. mid-update) no longer leaks that error.
