<!-- SUMMARY: Version upgrade protection -->

## Features

- New General-settings toggle **"Keep enabled during version upgrades"**. pfSense cannot tell a package or OS upgrade from a real uninstall, so pfBlockerNG is briefly disabled during upgrades; enable this to keep it active across them. New installs default to enabled; existing installs keep their prior behaviour on upgrade. Uninstalling through the Software page always performs a full removal ([#687](https://github.com/pfBlockerNG/pfBlockerNG/issues/687)).

## Improvements

- Update hook scripts can now react to package lifecycle passes: `PFB_POST_INSTALL` is set on an install/upgrade and `PFB_PRE_UNINSTALL` on an uninstall. Both are now described in the Hooks page help text ([#687](https://github.com/pfBlockerNG/pfBlockerNG/issues/687)).

## Bug Fixes

- The Update page no longer auto-scrolls when a Run Now is started, so the run controls stay in view.
