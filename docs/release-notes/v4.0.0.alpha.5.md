This is an alpha of the 4.0.0 series and is intended for testing. Do not run it on a
production firewall without a configuration backup; feedback and bug reports are welcome.

## Features

- **Reworked update & scheduling.** The Update page now offers explicit per-scope (IP /
  DNSBL) run controls with a force option and a schedule view. Updates run on a single
  periodic tick and apply changes as they are detected, with an optional quiet-hours window
  to defer applying during chosen times.

## Improvements

- **More robust compressed-feed handling.** Downloaded archive feeds are structurally
  validated before extraction: a valid archive that the system mislabels as a generic binary
  (`application/octet-stream`) is recovered and imported, 7-Zip feeds are accepted as
  first-class, common MIME-type variants are normalised, and a corrupt or truncated archive is
  rejected early with a clear message instead of failing deep in extraction.
- **Smarter feed change detection.** Feeds are compared by content hash rather than
  modification time, and remote feeds are fetched with a conditional request (ETag /
  If-Modified-Since) that honours "304 Not Modified" — so unchanged feeds are no longer
  re-downloaded or re-processed ([#572](https://github.com/pfBlockerNG/pfBlockerNG/issues/572)).
- **Lower-impact IP table updates.** IP block tables now reload only when their final address
  set actually changes, and the change is applied as an incremental add/remove delta rather
  than a full table replace — reducing churn and momentary disruption during updates.
- **Additional DoT/DoQ block controls** — a Reject-versus-Block action selector and an opt-in
  floating-rule mode for the encrypted-DNS block rules.
- **Restored per-list feed update frequency, scheduled log reset, and the force-both update
  action** ([#570](https://github.com/pfBlockerNG/pfBlockerNG/issues/570)).
- **Syslog and log-view polish** — a title-bar shortcut to the pfBlockerNG syslog, read-only
  Update-page log views, and a regrouped Log Settings layout with a mobile-layout fix.

## Bug Fixes

- **DNS Redirection and DoT/DoQ block settings now persist** correctly instead of being lost
  on save.
- **Auto-generated firewall rules no longer duplicate or reorder manually-defined user rules**
  ([#532](https://github.com/pfBlockerNG/pfBlockerNG/issues/532)).
- **An allow/permit feed no longer un-blocks an address blocked manually**
  ([#571](https://github.com/pfBlockerNG/pfBlockerNG/issues/571)).
- Fixed a settings checkbox that always appeared unchecked regardless of its saved value.
