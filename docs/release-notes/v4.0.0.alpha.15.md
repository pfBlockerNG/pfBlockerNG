## Improvements

- The Software tab's **Update** and **Uninstall** actions now hand off to pfSense's built-in Package Manager instead of running the package operation in-page. The Package Manager owns the operation and its progress display on a page that stays available while pfBlockerNG itself is being upgraded or removed, so the flow no longer depends on an endpoint that the operation is in the middle of replacing ([#684](https://github.com/pfBlockerNG/pfBlockerNG/issues/684)).
- Update hook scripts now receive `PFB_POST_INSTALL=1` on an install or upgrade and `PFB_PRE_UNINSTALL=1` on an uninstall, so a hook (for example the HAProxy graceful-reload recipe) can react to those package transitions in addition to normal update runs ([#684](https://github.com/pfBlockerNG/pfBlockerNG/issues/684)).

## Bug Fixes

- Update page live log: restored output that went missing in 4.0.0.alpha.14 — command-hook output, the firewall-filter restart line, and the closing update block now appear in the live view again. Also fixed duplicated lines when returning to the tab on mobile, and a completed uninstall now returns to the dashboard instead of a page that does not list the package ([#680](https://github.com/pfBlockerNG/pfBlockerNG/issues/680)).
