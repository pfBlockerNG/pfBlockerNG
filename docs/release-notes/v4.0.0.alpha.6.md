This is an alpha of the 4.0.0 series and is intended for testing. Do not run it on a
production firewall without a configuration backup; feedback and bug reports are welcome.

## Features

- **Update-page force modes.** A manual update can now choose how much of the pipeline to
  force — reuse cached feeds and only re-parse, re-download, or do both — instead of a single
  all-or-nothing force.

## Improvements

- **Clearer Feeds UI** — the "Unknown user defined" panel is now labelled "Custom Feeds".
- **Clearer 7-Zip feed message** — when a 7-Zip feed is configured but 7-Zip is not installed,
  the page now tells you to install it instead of failing obscurely.
- **UI polish** — corrected Update-page button spacing and Run Scope radio alignment, and
  fixed help text on the DNSBL IPs (alias name and IPv6 note) and States Removal pages.

## Bug Fixes

- **Sync target "enable" checkbox now persists** correctly instead of always reading as
  unchecked.
- **Update-page Cron Status** no longer falsely reports a missing cron task, and now shows the
  next scheduled tick.
- **Fixed false update hook timeouts** and a brittle Update-page log view.
- **Title-bar syslog shortcut** link now resolves correctly from any page.
