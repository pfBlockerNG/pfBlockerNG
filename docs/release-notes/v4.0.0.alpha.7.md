<!-- SUMMARY: logging, UI polish -->
This is an alpha of the 4.0.0 series and is intended for testing. Do not run it on a
production firewall without a configuration backup; feedback and bug reports are welcome.

## Improvements

- **ISO-8601 timestamps** in the logs and the dashboard widget, replacing the ambiguous
  month/day/year format.
- **Read-only output on the Software and Update pages**, with the log prefilled on a plain
  page load so recent activity is visible immediately.
- **pfctl table-operation failures now record the table, operation, and return code** in the
  log, making alias-table apply failures easier to diagnose.
- **Update-page polish** — clearer DNSBL Category state, improved Force-mode help text, and
  corrected button spacing.

## Bug Fixes

- Fixed a brief content flash when opening the Update page through the wizard link.
