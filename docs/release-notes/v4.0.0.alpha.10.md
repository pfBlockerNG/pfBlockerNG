This is an alpha of the 4.0.0 series and is intended for testing. Do not run it on a
production firewall without a configuration backup; feedback and bug reports are welcome.

## Improvements

- **DNSBL IP list (DNSBLIP) is no longer rebuilt every update** — the IPv4/IPv6 aliases of IPs extracted from DNSBL feeds are now reprocessed only when a source DNSBL feed actually changed (or the list is missing), instead of on every run ([#653](https://github.com/pfBlockerNG/pfBlockerNG/issues/653)).
- **Update and Software logs auto-scroll to the newest lines** — when either page is opened with a pre-filled log, it now scrolls to the bottom automatically, matching the live-run view.

## Bug Fixes

- **Aggregated IPv6 alias no longer contains mangled IPv4 addresses** — `pfB_<Type>_Aggregated_v6` was being passed through an IPv4-only tool, which turned the IPv6 union into bogus `0.0.x.y` entries. The IPv6 aggregate is now built correctly from the deduplicated union of its member sets.
