This is an alpha of the 4.0.0 series and is intended for testing. Do not run it on a
production firewall without a configuration backup; feedback and bug reports are welcome.

## Features

- **Pending changes banner.** After changing pfBlockerNG settings, the GUI now shows a banner noting that the change takes effect on the next list update, with a link to the Update page to run one immediately. The banner clears automatically once an update (manual or scheduled) applies the change.

## Improvements

- **Live log when opening the Update page mid-run** — loading the Update page while an update is in progress now tails the running log automatically, instead of showing only the previous run.
- **Clearer DNSBL VIP validation message** — when the configured sinkhole VIP is not on the expected interface, the message now reads "IPv4/IPv6 VIP not found on interface …".
- **Alias reload on upgrade** — existing installations keep the previous full-table alias reload; new installations default to the faster incremental (delta) apply.

## Bug Fixes

- **Accurate List Summary** — removed IP feeds no longer leave stale entries in the Last Updated / List Summary view.
- **Update-log line breaks** — fixed missing line breaks in the DNSBL VIP and disable update-log messages that ran consecutive entries together.
- **DNSBL help text** — fixed a stray line break in the DNSBL permit-rules help text.
