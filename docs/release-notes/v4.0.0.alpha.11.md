<!-- SUMMARY: Update log polish -->
## Improvements

- The update log's **Aliastables / Rules** section is now unambiguous: when firewall rules are unchanged but alias-table contents changed it no longer reads as a contradiction, and on a rule change it lists which pfBlockerNG rules were created, modified, or removed.
- Update statistics now report the **CIDR-aggregated address count** as the list's "Original" size.
- **Update hook scripts now live in their own directory** (`/usr/local/pkg/pfblockerng/hooks/`), separate from the per-feed transform scripts. If you authored update hooks under an earlier alpha, move them into this directory.

## Bug Fixes

- The **Update-page live log no longer goes silent while an update hook runs** — a hook's output now streams to the log as the hook executes, instead of appearing only after it finishes.
