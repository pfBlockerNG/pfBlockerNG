This is an incremental alpha in the 4.0.0 series, with fixes and refinements on
top of `v4.0.0.alpha.2`. It remains test-only: keep a config backup and do not
run it on a production firewall. Feedback and bug reports are welcome.

## Improvements

- **Self-hosted package repository install.** The setup script now points
  directly at the project's package catalog, and a boot-time hook regenerates
  the repository configuration so it stays correct automatically across pfSense
  upgrades. The previous routing indirection has been removed.

## Bug Fixes

- **Saving certain settings no longer errors.** Writing a legacy on/off value
  through the configuration layer — for example via Force Reload — could raise a
  type error; the write path now accepts those stored values directly.
